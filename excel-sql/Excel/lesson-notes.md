# جلسه ۱ — مقدمه و مفاهیم Spreadsheet

## Spreadsheet چیست؟
Spreadsheet محیطی جدولی برای ذخیره، محاسبه، سازمان‌دهی و نمایش داده است. داده‌ها در **Cell** قرار می‌گیرند و Cellها در قالب **Row** و **Column** سازمان‌دهی می‌شوند. یک فایل Excel معمولاً یک **Workbook** است و هر Workbook می‌تواند چند **Worksheet** داشته باشد.

## چرا Excel برای Data Analysis مهم است؟
Excel برای داده‌های کوچک و متوسط، تحلیل سریع، گزارش‌سازی، مدل‌سازی اولیه و ارتباط نتایج با افراد غیرتکنیکال بسیار مناسب است. مزیت اصلی آن سرعت تعامل و مشاهده مستقیم داده است؛ اما برای داده‌های بسیار حجیم، پردازش تکرارشونده و چندکاربره یا تحلیل‌های کاملاً قابل‌اتکا، ابزارهایی مثل SQL، Python و BI معمولاً مناسب‌ترند.

## Excel در برابر Google Sheets
هر دو ابزار Spreadsheet هستند. Excel معمولاً امکانات تحلیلی، مدل‌سازی و قابلیت‌های پیشرفته بیشتری دارد؛ Google Sheets برای همکاری هم‌زمان و کار مبتنی بر Cloud بسیار مناسب است. انتخاب ابزار باید بر اساس مسئله، حجم داده، نیاز به همکاری و محیط کاری انجام شود.

## اصل مهم
Excel را نباید فقط به‌عنوان «ماشین حساب جدولی» دید. در Data Analysis، Excel یک محیط برای **Data Preparation → Analysis → Visualization → Reporting** است.

### تمرین
برای سناریوهای «لیست شخصی هزینه‌ها»، «فروشگاه با چند میلیون رکورد»، «گزارش تیم ۵ نفره» و «مدل مالی پیچیده» ابزار مناسب را انتخاب و دلیل خود را بنویسید.

# جلسه ۲ — محیط Excel و پایه فرمول‌نویسی

## مفاهیم پایه
- **Cell:** محل تقاطع Row و Column؛ مانند `B4`
- **Range:** مجموعه‌ای از Cellها؛ مانند `B4:D10`
- **Workbook:** فایل Excel
- **Worksheet:** برگه داخل Workbook

هر Cell می‌تواند متن، عدد، تاریخ، مقدار منطقی یا Formula داشته باشد.

## Formula
فرمول با `=` شروع می‌شود:

```excel
=A2+B2
=B2*C2
=(B2-C2)/C2
```

اولویت عملگرها را رعایت کنید و برای خوانایی از پرانتز استفاده کنید.

## Referenceها
در `=B2*C2` هر دو Reference نسبی‌اند و با Copy کردن فرمول تغییر می‌کنند. در `$B$2` هم Column و هم Row ثابت‌اند. در `$B2` فقط Column و در `B$2` فقط Row ثابت است.

این موضوع برای ساخت مدل‌هایی مثل محاسبه مالیات، تخفیف یا نرخ تبدیل بسیار مهم است.

## توابع عددی پایه
توابعی مثل `SUM`, `AVERAGE`, `MIN`, `MAX`, `ROUND` برای محاسبات رایج استفاده می‌شوند.

```excel
=SUM(B2:B20)
=AVERAGE(C2:C20)
=ROUND(D2,2)
```

### تمرین
یک جدول فروش با ستون‌های Product، Quantity، Unit Price و Total Price بسازید و Total Price را با فرمول محاسبه کنید. سپس مجموع فروش، میانگین فروش و بیشترین فروش را به دست آورید.

# جلسه ۳ — Formatting و سازمان‌دهی داده

Formatting باید برای **خوانایی و انتقال معنا** استفاده شود، نه صرفاً زیبایی.

## Number Formatting
عدد، درصد، ارز و تاریخ باید با قالب مناسب نمایش داده شوند. Formatting مقدار واقعی Cell را تغییر نمی‌دهد؛ فقط نحوه نمایش را تغییر می‌دهد.

## Conditional Formatting
برای برجسته‌کردن الگوها و استثناها کاربرد دارد؛ مثلاً فروش کمتر از هدف، مقادیر تکراری یا Top/Bottom values.

## سازمان‌دهی
- یک ردیف Header مشخص داشته باشید.
- در جدول داده خام از Merge کردن Cellها اجتناب کنید.
- هر Column یک مفهوم مشخص داشته باشد.
- یک Row نماینده یک رکورد باشد.
- از Blank Row در وسط Dataset پرهیز کنید.
- عنوان گزارش را از خود Data Table جدا کنید.

## میانبرهای مهم
`Ctrl + C`, `Ctrl + V`, `Ctrl + Z`, `Ctrl + F`, `Ctrl + Arrow`, `Ctrl + Shift + Arrow`, `Ctrl + 1` و `F4` از میانبرهای بسیار کاربردی‌اند.

### تمرین
یک گزارش فروش نامرتب را طوری اصلاح کنید که Header، نوع داده، درصدها، اعداد و وضعیت‌های مهم واضح باشند؛ سپس سه Conditional Formatting معنادار اضافه کنید.

# جلسه ۴ — ورود و پاک‌سازی داده

داده خام معمولاً تمیز نیست. قبل از تحلیل باید کیفیت آن را بررسی کنیم.

## مشکلات رایج
- فاصله اضافی
- نام‌های متفاوت برای یک مقدار
- Duplicate
- Missing Value
- نوع داده اشتباه
- تاریخ‌های ناسازگار
- متن در ستون عددی

## ابزارها و توابع
`TRIM` برای حذف فاصله‌های اضافی، `CLEAN` برای حذف برخی کاراکترهای غیرقابل‌چاپ، `SUBSTITUTE` برای جایگزینی متن و `Text to Columns` برای شکستن داده کاربرد دارند.

مثال:

```excel
=TRIM(A2)
=SUBSTITUTE(A2,"-"," ")
```

## اصل مهم Data Cleaning
قبل از حذف یا تغییر داده باید بدانیم **چرا** آن داده مشکل دارد. پاک‌سازی بدون درک منبع داده ممکن است اطلاعات واقعی را از بین ببرد.

### Workflow
`Raw Data → Profile → Clean → Validate → Analysis`

### تمرین
یک فایل شامل نام مشتری، شهر، تاریخ و مبلغ بسازید که عمداً فاصله اضافی، Duplicate و فرمت متفاوت تاریخ داشته باشد. نسخه Clean تولید کنید و تمام تغییرات را ثبت کنید.

# جلسه ۵ — Filter، Validation و ترکیب داده

## Sort و Filter
Sort ترتیب نمایش داده‌ها را تغییر می‌دهد؛ Filter رکوردهای نامرتبط با شرط را پنهان می‌کند.

فیلتر را برای پاسخ به سؤال‌هایی مثل «فروش‌های بالاتر از X در شهر Y» استفاده کنید.

## Data Validation
برای کنترل ورودی داده است. نمونه‌ها:
- فهرست انتخابی برای شهر
- محدودکردن عدد به بازه مشخص
- محدودکردن تاریخ

Validation از ورود خطا جلوگیری می‌کند و بخشی از Data Quality است.

## ترکیب داده‌ها
وقتی چند فایل یا چند بخش داده داریم، ابتدا باید ساختار مشترک را مشخص کنیم. ستون‌های هم‌معنا باید نام و نوع سازگار داشته باشند.

### تمرین
فرم ورود سفارش طراحی کنید که Product از یک Dropdown انتخاب شود، Quantity فقط عدد مثبت باشد و Date مقدار معتبر داشته باشد. سپس سفارش‌های چند ماه را در یک جدول استاندارد ادغام کنید.

# جلسه ۶ — Lookup و اتصال اطلاعات

گاهی اطلاعات مورد نیاز در جدول دیگری قرار دارد. Lookup برای پیدا کردن مقدار مرتبط بر اساس یک Key استفاده می‌شود.

## VLOOKUP
ساختار کلی:

```excel
=VLOOKUP(A2,Products!A:D,4,FALSE)
```

`FALSE` یعنی تطبیق دقیق.

## HLOOKUP
مشابه VLOOKUP است اما جست‌وجو را افقی انجام می‌دهد و در پروژه‌های جدید کمتر مورد استفاده قرار می‌گیرد.

## INDEX + MATCH
این ترکیب انعطاف بیشتری دارد:

```excel
=INDEX(D:D,MATCH(A2,A:A,0))
```

`MATCH` محل Key را پیدا می‌کند و `INDEX` مقدار مورد نظر را برمی‌گرداند.

## خطاهای رایج
- Key تکراری
- فاصله اضافی
- نوع داده متفاوت
- Lookup اشتباه روی approximate match
- نبودن مقدار مورد جست‌وجو

### تمرین
جدول Orders را به Products و Customers متصل کنید و Product Category، Customer City و Unit Price را به جدول سفارش اضافه کنید.

# جلسه ۷ — IF، منطق و توابع متن

## IF
برای تصمیم‌گیری شرطی:

```excel
=IF(D2>=1000000,"High","Low")
```

## منطق چندشرطی
`AND` زمانی True است که همه شروط برقرار باشند؛ `OR` زمانی True است که حداقل یکی برقرار باشد.

```excel
=IF(AND(B2="Tehran",C2>100),"Priority","Normal")
```

`IFERROR` برای کنترل خروجی خطا مفید است، اما نباید خطاهای واقعی را بی‌صدا پنهان کند.

## توابع متن
`LEFT`, `RIGHT`, `MID`, `LEN`, `FIND`, `SEARCH`, `SUBSTITUTE`, `CONCAT`, `TEXTJOIN` برای استخراج و تبدیل متن کاربرد دارند.

مثلاً:

```excel
=LEFT(A2,3)
=LEN(A2)
=TEXTJOIN("-",TRUE,A2:C2)
```

### تمرین
از یک ستون Customer Code، شهر و نوع مشتری را استخراج کنید و با IF مشتریان را به گروه‌های Gold/Silver/Standard تقسیم کنید.

# جلسه ۸ — Tables، Ranges و Array Formula

## Excel Table
Table ساختار داده را استاندارد می‌کند و با اضافه‌شدن رکورد جدید، فرمول‌ها و Formatting را بهتر مدیریت می‌کند.

مزیت مهم آن **Structured Reference** است:

```excel
=SUM(Sales[Revenue])
```

## Dynamic Array
در نسخه‌های جدید Excel، برخی توابع می‌توانند چند خروجی را به‌صورت Spill تولید کنند. توابعی مثل `FILTER`, `SORT`, `UNIQUE` بسیار کاربردی‌اند.

```excel
=UNIQUE(Sales[City])
=FILTER(Sales,Sales[Revenue]>1000000)
```

## Array Formula
مفهوم Array یعنی به‌جای فکرکردن به یک Cell، با مجموعه‌ای از مقادیر کار کنیم. در Excel جدید بسیاری از محاسبات آرایه‌ای ساده‌تر شده‌اند.

## حل دستگاه معادلات
برای مدل‌های کوچک می‌توان از ماتریس‌ها و توابعی مانند `MMULT` و `MINVERSE` استفاده کرد؛ این بخش باید به‌عنوان کاربرد تکمیلی دیده شود، نه مهارت اصلی Data Analyst.

### تمرین
یک Table فروش بسازید، فهرست شهرهای یکتا را تولید کنید، فقط سفارش‌های بالاتر از یک آستانه را با FILTER استخراج کنید و گزارش را طوری طراحی کنید که با اضافه‌شدن رکورد جدید نیاز به اصلاح دستی نداشته باشد.

# جلسه ۹ — آمار توصیفی و همبستگی

## آمار توصیفی
- Mean: میانگین
- Median: میانه
- Mode: نما
- Variance: واریانس
- Standard Deviation: انحراف معیار
- Percentile: صدک

Mean تحت تأثیر Outlier قرار می‌گیرد؛ Median معمولاً برای داده‌های دارای چولگی مقاوم‌تر است.

## Correlation
همبستگی شدت و جهت رابطه خطی دو متغیر را اندازه‌گیری می‌کند. مقدار آن بین -1 و +1 است.

Correlation به معنی **علیت** نیست. اگر دو متغیر همبستگی بالایی دارند، نمی‌توان نتیجه گرفت یکی علت دیگری است.

### تمرین
زمان پاسخ‌گویی و رضایت مشتری را بررسی کنید. Mean و Median را مقایسه کنید، Outlierها را پیدا کنید و Correlation را محاسبه کنید. در پایان یک تفسیر کوتاه بنویسید.

# جلسه ۱۰ — T-Test، ANOVA و Chi-square

این ابزارها برای پاسخ به سؤال‌های آماری استفاده می‌شوند، نه صرفاً تولید یک p-value.

## T-Test
برای مقایسه میانگین دو گروه در شرایط مناسب استفاده می‌شود. باید نوع آزمون و فرض‌های آن را بشناسیم.

## ANOVA
برای مقایسه میانگین بیش از دو گروه کاربرد دارد. معنی‌دارشدن ANOVA فقط می‌گوید حداقل یک تفاوت وجود دارد؛ برای فهمیدن اینکه کدام گروه‌ها متفاوت‌اند، به تحلیل‌های تکمیلی نیاز داریم.

## Chi-square
برای بررسی ارتباط بین متغیرهای طبقه‌ای کاربرد دارد.

## تفسیر
p-value را نباید با «احتمال درست بودن فرضیه» یکی دانست. علاوه بر معناداری آماری، اندازه اثر و اهمیت عملی نیز مهم است.

### تمرین
سه گروه مشتری را از نظر میانگین خرید مقایسه کنید و در سناریویی دیگر ارتباط جنسیت محصول و وضعیت خرید را با Chi-square بررسی کنید. نتیجه را با زبان کسب‌وکار توضیح دهید.

# جلسه ۱۱ — Regression و مدل‌سازی

Regression برای مدل‌کردن رابطه بین متغیر هدف و یک یا چند متغیر توضیحی استفاده می‌شود.

در رگرسیون خطی ساده:

`y = β0 + β1x + ε`

`β1` تغییر مورد انتظار y به ازای یک واحد تغییر x را نشان می‌دهد، تحت فرض‌های مدل.

## R²
معیاری از میزان تغییرپذیری توضیح‌داده‌شده توسط مدل است؛ R² بالا به‌تنهایی مدل خوب را تضمین نمی‌کند.

## خطا و Residual
تفاوت مقدار واقعی و مقدار پیش‌بینی‌شده Residual است. بررسی Residualها برای تشخیص مشکلات مدل مهم است.

## Forecasting
پیش‌بینی باید با احتیاط انجام شود. رابطه تاریخی لزوماً در آینده ثابت نمی‌ماند.

### تمرین
Revenue را بر اساس Advertising Spend مدل کنید. ضریب، R² و Residualها را بررسی کنید و توضیح دهید آیا مدل برای تصمیم‌گیری قابل استفاده است یا خیر.

# جلسه ۱۲ — Data Visualization

هدف نمودار، **انتقال پیام داده‌ای** است.

## انتخاب نمودار
- Column/Bar: مقایسه دسته‌ها
- Line: روند زمانی
- Scatter: رابطه دو متغیر
- Histogram: توزیع
- Pie: سهم چند دسته محدود؛ با احتیاط
- Combo: ترکیب دو نوع اندازه‌گیری با مقیاس متفاوت
- Bubble: نمایش سه متغیر؛ فقط وقتی خوانایی حفظ شود
- Radar: کاربرد محدود و مقایسه چند ویژگی؛ معمولاً انتخاب اول تحلیل نیست

## اصول
عنوان باید پیام را روشن کند. محور، واحد و Legend مشخص باشند. از 3D و تزئینات غیرضروری پرهیز کنید.

نمودار خوب به سؤال «خب که چی؟» پاسخ می‌دهد.

### تمرین
برای یک Dataset فروش، سه سؤال بسازید و برای هرکدام مناسب‌ترین نمودار را انتخاب کنید. سپس یک نمودار عمداً بد طراحی کنید و ایرادهای آن را توضیح دهید.

---

# جلسه ۱۳ — Pivot Table و Pivot Chart

Pivot Table یکی از سریع‌ترین ابزارهای خلاصه‌سازی داده در Excel است.

چهار ناحیه اصلی:
- Rows
- Columns
- Values
- Filters

مثلاً می‌توان Revenue را بر اساس City و Month خلاصه کرد.

## تکنیک‌ها
Grouping تاریخ، تغییر نوع Aggregation، درصد از Total، Sort و Filter از کاربردهای مهم‌اند.

## Pivot Chart
برای نمایش نتیجه Pivot Table استفاده می‌شود. Slicer نیز فیلتر تعاملی مناسبی برای گزارش است.

### تمرین
داده فروش را بر اساس شهر، محصول و ماه خلاصه کنید. سپس Pivot Chart و Slicer بسازید تا کاربر بتواند شهر را انتخاب کند.

# جلسه ۱۴ — Dashboard

Dashboard صفحه‌ای برای نمایش **KPIها، روندها و نکات کلیدی** است؛ نه مجموعه‌ای از نمودارهای رنگارنگ.

## ساختار پیشنهادی
1. عنوان و محدوده زمانی
2. KPI Cards
3. روند اصلی
4. Breakdownهای مهم
5. Filter/Slicer
6. Insight یا توضیح مدیریتی

## KPI
هر KPI باید تعریف مشخص، واحد، بازه زمانی و منبع داده داشته باشد.

## تعامل
Slicer، Pivot Chart و Form Controls می‌توانند گزارش را تعاملی کنند. تعامل باید به سؤال کاربر کمک کند، نه اینکه صرفاً جذابیت بصری ایجاد کند.

### تمرین
Dashboard فروش بسازید که حداقل Revenue، Orders، Average Order Value، روند ماهانه و فروش بر اساس Category را نمایش دهد و با Slicer قابل فیلتر باشد.
