# جلسه ۱ — وارد کردن داده از فایل‌ها در Excel

## 🎯 هدف جلسه

در این جلسه یاد می‌گیریم چگونه داده‌ای را که خارج از فایل فعلی Excel قرار دارد وارد کنیم. قرار نیست همیشه داده را سلول‌به‌سلول تایپ کنیم؛ در کار واقعی، بخش زیادی از اطلاعات از فایل‌های دیگر یا منابع خارجی به دست ما می‌رسد.

در پایان جلسه باید بتوانید:

- تفاوت ورود دستی و Import را توضیح دهید.
- فایل‌های Excel و CSV را وارد کنید.
- قبل از Load کردن، ساختار داده را بررسی کنید.
- برای CSV جداکننده مناسب انتخاب کنید.
- بین `Load`، `Load To` و `Transform Data` تفاوت قائل شوید.
- مفهوم کلی Connection را درک کنید.

---

# ۱. چرا Data Import مهم است؟

تصور کنید تحلیلگر فروش یک شرکت هستید و هر روز گزارشی در قالب فایل CSV برای شما ارسال می‌شود. آیا منطقی است هر روز چند هزار ردیف را Copy/Paste کنید؟ طبیعتاً نه.

در کار حرفه‌ای بهتر است مسیر ورود داده تا حد امکان **تکرارپذیر** باشد:

```text
Source File
   ↓
Import
   ↓
Inspect
   ↓
Transform
   ↓
Load
```

این رویکرد هم خطای انسانی را کمتر می‌کند و هم باعث می‌شود دفعه بعد بتوانیم همان مسیر را دوباره اجرا کنیم.

---

# ۲. Get Data کجاست؟

در Excel ابزارهای وارد کردن داده عمدتاً در برگه‌ی **Data** و بخش **Get & Transform Data** قرار دارند.

برای مثال مسیر کلی برای یک فایل Excel به شکل زیر است:

```text
Data
→ Get Data
→ From File
→ From Excel Workbook
```

برای CSV نیز می‌توانیم از مسیر:

```text
Data
→ Get Data
→ From File
→ From Text/CSV
```

استفاده کنیم.

> **یادآوری:** نام دقیق بعضی گزینه‌ها ممکن است بسته به نسخه یا تنظیمات Excel کمی متفاوت باشد، اما منطق کار یکسان است.

---

# ۳. وارد کردن یک فایل Excel دیگر

فرض کنید فایل زیر را دریافت کرده‌ایم:

```text
monthly_sales.xlsx
```

داخل این فایل سه Sheet وجود دارد:

- `January`
- `February`
- `March`

می‌خواهیم اطلاعات یکی از Sheetها را وارد Workbook فعلی کنیم.

### مراحل

1. به برگه‌ی **Data** بروید.
2. `Get Data → From File → From Excel Workbook` را انتخاب کنید.
3. فایل موردنظر را باز کنید.
4. Excel پنجره‌ای با فهرست Sheetها و Tableهای موجود نمایش می‌دهد.
5. مورد موردنظر را انتخاب کنید.
6. یکی از روش‌های بارگذاری را انتخاب کنید.

---

## ۳.۱ گزینه Load

با `Load` داده را به Workbook وارد می‌کنیم تا برای استفاده در Excel آماده باشد.

این روش زمانی مناسب است که داده تقریباً آماده است و پیش از ورود تغییر خاصی روی آن لازم نداریم.

---

## ۳.۲ گزینه Load To

`Load To` کنترل بیشتری روی محل خروجی می‌دهد.

مثلاً می‌توانیم تعیین کنیم داده:

- در یک Worksheet جدید قرار گیرد؛
- در یک Sheet موجود Load شود؛
- یا بسته به سناریو به شکل دیگری در Workbook قرار گیرد.

این گزینه زمانی مفید است که ساختار فایل برایمان مهم باشد.

---

## ۳.۳ گزینه Transform Data

این گزینه یکی از مهم‌ترین قسمت‌های Data Preparation است.

با انتخاب `Transform Data`، قبل از وارد کردن نهایی داده، وارد **Power Query Editor** می‌شویم.

در آنجا می‌توانیم مثلاً:

- ستون اضافه را حذف کنیم؛
- نام ستون را عوض کنیم؛
- نوع داده را اصلاح کنیم؛
- ردیف‌های غیرضروری را فیلتر کنیم؛
- متن را Split یا Replace کنیم؛
- چند داده را ترکیب کنیم.

پس:

> **Load = بیاور و استفاده کن**
>
> **Transform Data = قبل از آوردن، داده را آماده کن**

---

# ۴. ورود فایل CSV

CSV مخفف **Comma-Separated Values** است؛ هرچند در عمل جداکننده الزاماً کاما نیست.

یک نمونه فایل CSV را ببینید:

```text
Product,Price,Quantity
Mouse,720000,4
Keyboard,1450000,2
Monitor,8500000,3
```

در این مثال، جداکننده `,` است.

اما ممکن است CSV شما با `;` ساخته شده باشد:

```text
Product;Price;Quantity
Mouse;720000;4
Keyboard;1450000;2
Monitor;8500000;3
```

بنابراین هنگام Import باید به **Delimiter** توجه کنیم.

---

# ۵. Preview را جدی بگیرید

بعد از انتخاب CSV، Excel معمولاً پیش‌نمایش داده را نمایش می‌دهد.

این بخش را نباید صرفاً یک مرحله‌ی اضافی ببینیم. قبل از Load بهتر است بررسی کنیم:

- آیا ستون‌ها درست جدا شده‌اند؟
- آیا Header درست تشخیص داده شده؟
- آیا عددها به شکل عدد خوانده شده‌اند؟
- آیا تاریخ‌ها درست تشخیص داده شده‌اند؟
- آیا کاراکترهای عجیب یا متن‌های به‌هم‌ریخته دیده می‌شود؟

اگر همه‌ی اطلاعات در یک ستون قرار گرفته بود، اولین چیزی که باید بررسی کنیم **Delimiter** است.

---

# ۶. یک مثال واقعی

فرض کنید فایل زیر را از تیم فروش دریافت کرده‌ایم:

```text
order_id;customer;city;amount
1001;Nima;Tehran;5400000
1002;Sara;Shiraz;2700000
1003;Nima;Tehran;1800000
```

اگر Excel انتظار `,` داشته باشد ولی داده با `;` جدا شده باشد، احتمالاً همه‌ی اطلاعات را در یک Column خواهیم دید.

در این حالت باید Delimiter را روی `Semicolon` قرار دهیم.

این مثال ساده، یکی از رایج‌ترین مشکلات واقعی هنگام دریافت فایل است.

---

# ۷. Copy/Paste یا Import؟

ممکن است بگویید:

> «خب فایل را باز می‌کنم و Copy/Paste می‌کنم. چه نیازی به این همه مراحل است؟»

برای یک فایل کوچک و کار یک‌باره، Copy/Paste می‌تواند کاملاً منطقی باشد.

اما اگر قرار باشد همین کار هر هفته یا هر روز تکرار شود، Import مزیت مهمی پیدا می‌کند.

مثلاً:

```text
گزارش هفته اول → Import
گزارش هفته دوم → Refresh
گزارش هفته سوم → Refresh
```

به‌جای اینکه مسیر را از ابتدا با Copy/Paste تکرار کنیم.

---

# ۸. Queries & Connections چیست؟

وقتی از ابزارهای Get Data استفاده می‌کنیم، Excel می‌تواند اطلاعات مربوط به منبع و فرآیند ورود را نگهداری کند.

این اطلاعات را می‌توان در **Queries & Connections** مشاهده کرد.

از این بخش، بسته به نوع اتصال و Query، می‌توان کارهایی مثل:

- Refresh
- ویرایش Query
- تغییر نحوه Load
- حذف اتصال

را مدیریت کرد.

### Refresh یعنی چه؟

فرض کنید امروز فایل منبع را وارد کرده‌ایم. فردا همان فایل با داده‌های جدید به‌روزرسانی شده است.

به‌جای ساختن دوباره فرایند، می‌توانیم Query را **Refresh** کنیم تا داده‌ها دوباره از منبع خوانده شوند.

> توجه کنید که «قابل Refresh بودن» به این معنی نیست که هر تغییر منبع بدون هیچ محدودیتی وارد Excel می‌شود؛ مسیر Query، نام ستون‌ها و ساختار منبع هم اهمیت دارند.

---

# ۹. تمرین عملی

یک فایل Excel با نام `sales_source.xlsx` بسازید و داخل آن دو Sheet ایجاد کنید:

- `Orders`
- `Products`

سپس یک فایل CSV با حداقل ۲۰ سفارش ایجاد کنید.

### کارهایی که باید انجام دهید

1. فایل Excel را با `From Excel Workbook` وارد کنید.
2. CSV را با `From Text/CSV` وارد کنید.
3. قبل از Load کردن Preview را بررسی کنید.
4. در صورت نیاز Delimiter را اصلاح کنید.
5. داده یکی از منابع را با `Transform Data` باز کنید.
6. Query ایجادشده را در `Queries & Connections` پیدا کنید.
7. مقدار یکی از رکوردهای منبع را تغییر دهید و نتیجه‌ی Refresh را بررسی کنید.

---

# 🧠 نکات کلیدی

> **Import کردن داده یعنی ساختن یک مسیر منظم برای دریافت داده، نه صرفاً Copy/Paste کردن آن.**

> **Preview مرحله‌ای مهم برای پیدا کردن مشکلات اولیه‌ی داده است.**

> **Delimiter نامناسب می‌تواند کل CSV را به یک ستون تبدیل کند.**

> **Transform Data زمانی به کار می‌آید که داده قبل از Load نیاز به آماده‌سازی داشته باشد.**

> **Connection و Query می‌توانند فرایند دریافت داده را قابل Refresh و تکرار کنند.**
