# فصل ۳ — کار با داده‌ها و پاک‌سازی

> **هدف فصل:** یاد می‌گیریم داده‌هایی را که از فایل‌ها، منابع خارجی یا پایگاه‌داده می‌آیند وارد Excel کنیم، کیفیت آن‌ها را بررسی و اصلاح کنیم، داده‌های موردنیاز را جدا کنیم، چند منبع را به هم متصل کنیم و در نهایت یک Dataset قابل‌اعتماد برای تحلیل بسازیم.

## چرا این فصل مهم است؟

در پروژه‌های واقعی، معمولاً تحلیلگر کارش را با یک جدول مرتب و آماده شروع نمی‌کند. داده ممکن است در چند فایل پراکنده باشد، نام‌ها با شکل‌های مختلف نوشته شده باشند، بعضی مقادیر خالی باشند، چند رکورد تکراری وجود داشته باشد یا یک ستون چند مفهوم متفاوت را در خود جا داده باشد.

بنابراین بخش مهمی از Data Analysis قبل از خودِ تحلیل اتفاق می‌افتد: **Data Preparation**.

```text
External Data
      ↓
Import
      ↓
Profile / Inspect
      ↓
Clean & Transform
      ↓
Sort / Filter
      ↓
Combine
      ↓
Validate
      ↓
Analysis-ready Data
```

## جلسات این فصل

| جلسه | عنوان | خروجی عملی |
|---|---|---|
| 01 | ورود داده از فایل‌ها | وارد کردن Excel و CSV به‌صورت ساختاریافته |
| 02 | اتصال به منابع و Power Query | ساخت Connection و آماده‌سازی قبل از Load |
| 03 | پاک‌سازی داده و حذف Duplicate | ساخت نسخه‌ی تمیزتر از داده خام |
| 04 | Missing Data و اصلاح متن | مدیریت سلول‌های خالی و ناسازگاری‌های متنی |
| 05 | Sort و Filter | استخراج سریع رکوردهای موردنیاز |
| 06 | Append و Merge | ترکیب داده‌ها از چند جدول و منبع |
| 07 | Consolidate و تجمیع داده | ساخت خروجی تجمیعی از چند محدوده مشابه |
| 08 | Data Validation و تمرین یکپارچه | کنترل کیفیت ورود داده و اجرای Workflow کامل |

## خروجی نهایی فصل

در پایان فصل باید بتوانید یک داده خام را از یک یا چند منبع دریافت کنید، مشکل‌های رایج آن را پیدا کنید، اصلاحات لازم را انجام دهید و Datasetی بسازید که برای فرمول‌نویسی، Pivot Table و Visualization در فصل‌های بعدی آماده باشد.

---

## تمرین پیشنهادی فصل

یک فایل فروش خام با حداقل ۳۰۰ رکورد تهیه کنید و عمداً چند مشکل واقعی داخل آن ایجاد کنید:

- چند نام مشتری با فاصله‌ی اضافی
- چند مقدار خالی
- چند رکورد تکراری
- چند تاریخ با فرمت متفاوت
- چند مقدار اشتباه در نام شهر یا محصول
- حداقل دو جدول جداگانه برای ترکیب

سپس با ابزارهای این فصل، فایل را به یک Dataset تمیز و استاندارد تبدیل کنید.

> **نکته:** در این فصل حذف داده هدف نیست؛ **ساختن داده‌ی قابل اعتماد** هدف است.
