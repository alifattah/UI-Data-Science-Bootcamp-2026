# جلسه ۵ — Scatter و Bubble Charts

## یک تفاوت مهم: Category در برابر Value

یکی از اشتباه‌های رایج این است که Line Chart و Scatter Plot را صرفاً به خاطر شباهت ظاهری یکسان بدانیم.

در `Line Chart` محور افقی معمولاً یک Category یا ترتیب مشخص دارد. اما در `Scatter Chart` هر نقطه یک جفت مقدار عددی `X` و `Y` است.

---

## 1. Scatter Plot چیست؟

فرض کنید برای چند کمپین تبلیغاتی دو مقدار داریم:

- هزینه تبلیغات
- میزان فروش

می‌توانیم هزینه را روی محور X و فروش را روی محور Y قرار دهیم.

هر نقطه در واقع یک مشاهده را نشان می‌دهد:

```text
X = Advertising Spend
Y = Sales
```

این نمودار برای دیدن رابطه، خوشه‌ها، Outlierها و شکل کلی ارتباط بسیار مناسب است.

---

## 2. Scatter در برابر Line

فرض کنید Xهای ما این باشند:

```text
1, 2, 8, 20
```

فاصله واقعی بین `2` و `8` با فاصله `1` و `2` یکسان نیست.

Scatter این فاصله واقعی را حفظ می‌کند، اما در یک Line Chart دسته‌ها معمولاً با فاصله‌های مساوی روی محور قرار می‌گیرند.

بنابراین وقتی محور X یک متغیر عددی واقعی است، Scatter معمولاً انتخاب مناسب‌تری است.

---

## 3. چه زمانی Scatter مناسب است؟

- بررسی رابطه دو متغیر عددی
- تحلیل Outlier
- بررسی الگوی خطی یا غیرخطی
- وقتی فاصله‌های X اهمیت دارند
- مقایسه تعداد زیادی مشاهده عددی

---

## 4. انواع Scatter در Excel

Excel چند حالت رایج ارائه می‌دهد:

- Scatter با نقاط ساده
- Scatter با خطوط مستقیم
- Scatter با خطوط نرم
- حالت‌های همراه یا بدون Marker

برای تحلیل داده، حالت ساده اغلب اولین انتخاب خوبی است چون بدون اضافه کردن خطوط ممکن است ساختار واقعی نقاط واضح‌تر دیده شود.

---

# 5. Bubble Chart

Bubble Chart را می‌توان توسعه‌ای از Scatter دانست که **متغیر سوم** را با اندازه نقطه نمایش می‌دهد.

مثلاً برای شهرها:

| City | Factories | Income | Population |
|---|---:|---:|---:|
| A | 42 | 780 | 2.8 |
| B | 25 | 620 | 1.9 |
| C | 61 | 910 | 4.1 |

می‌توانیم:

```text
X → Factories
Y → Income
Bubble Size → Population
```

حالا یک نمودار داریم که سه متغیر عددی را هم‌زمان نشان می‌دهد.

---

## 6. محدودیت Bubble

اندازه حباب از نظر ادراک بصری همیشه مثل طول یک میله دقیق قابل مقایسه نیست. بنابراین Bubble برای نمایش الگوی کلی عالی است، اما برای مقایسه دقیق مقادیر، جدول یا نمودارهای ساده‌تر معمولاً بهترند.

همچنین تعداد زیاد حباب می‌تواند خوانایی را کاهش دهد.

---

## 7. افزودن Data Labels

وقتی نقاط یا حباب‌ها مربوط به نام‌های مشخصی هستند، می‌توان `Data Labels` را فعال کرد تا مثلاً نام شهر کنار هر حباب دیده شود.

اما Label را فقط زمانی اضافه کنید که واقعاً به فهم نمودار کمک کند؛ تعداد زیاد برچسب می‌تواند نمودار را شلوغ کند.

---

## 🧪 تمرین

یک Dataset با حداقل ۲۰ مشتری بسازید:

`Advertising Spend | Revenue | Customer Count`

1. Scatter رسم کنید.
2. رابطه Spend و Revenue را بررسی کنید.
3. یک Outlier ایجاد کنید.
4. همان داده را به Bubble تبدیل کنید و Customer Count را Size قرار دهید.
5. Data Labels را فقط برای نقاط مهم اضافه کنید.

---

## ✅ خلاصه

- Scatter برای رابطه دو متغیر عددی عالی است.
- Scatter فاصله واقعی مقادیر X را حفظ می‌کند.
- Bubble یک متغیر سوم را به اندازه نقطه تبدیل می‌کند.
- هرچه نقاط و Labelها بیشتر شوند، خوانایی مهم‌تر می‌شود.
