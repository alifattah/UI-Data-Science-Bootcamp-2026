# فصل ۶ — مصورسازی داده‌ها در Excel

> نمودار خوب قرار نیست فقط فایل را زیباتر کند؛ باید فهمیدن داده و انتقال پیام آن را آسان‌تر کند.

## اهداف فصل

در این فصل یاد می‌گیریم:

- قبل از ساخت نمودار، سؤال تحلیلی را مشخص کنیم.
- انواع اصلی Chartهای Excel را بشناسیم.
- Column و Bar را برای مقایسه‌ها به کار ببریم.
- Line Chart را برای روند و داده زمانی استفاده کنیم.
- Pie و Doughnut را با درک محدودیت‌هایشان به کار ببریم.
- Radar، Combo، Scatter، Bubble و Histogram را بشناسیم.
- نمودار را برای خوانایی و انتقال بهتر پیام شخصی‌سازی کنیم.
- بین نمودار «زیبا» و نمودار «تحلیلی» تفاوت بگذاریم.

## مسیر جلسات

| جلسه | عنوان | خروجی |
|---|---|---|
| 01 | اصول Visualization و ساخت نمودار | ساخت اولین Chart و شناخت اجزای آن |
| 02 | Bar و Column Charts | مقایسه دسته‌ها |
| 03 | Line Charts | تحلیل روند و زمان |
| 04 | Pie، Doughnut، Radar و Combo | نمایش سهم و مقایسه چندبعدی/دو مقیاسی |
| 05 | Scatter و Bubble | رابطه و سه متغیر عددی |
| 06 | Histogram | درک توزیع و Bins |
| 07 | طراحی و شخصی‌سازی نمودار | ساخت Chart قابل ارائه و تفسیر |

## اصل طلایی فصل

> **اول سؤال، بعد داده، بعد انتخاب نمودار. نه برعکس.**
