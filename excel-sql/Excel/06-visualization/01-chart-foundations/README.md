# جلسه ۱ — مبانی Chart و انتخاب نمودار مناسب

## چرا نمودار می‌سازیم؟

وقتی داده زیاد است، دیدن چند صد عدد پشت سر هم معمولاً برای پیدا کردن الگو کافی نیست. نمودار می‌تواند اطلاعات را فشرده‌تر نمایش دهد و به ما کمک کند روند، اختلاف یا الگوی مهم را سریع‌تر ببینیم.

اما یک هشدار مهم:

> **هدف نمودار «زیباتر کردن Excel» نیست؛ هدف، انتقال یک پیام از داده است.**

---

## 1. قبل از نمودار سؤال بپرسید

قبل از رفتن به `Insert → Charts` بپرسید:

- می‌خواهم چه چیزی را مقایسه کنم؟
- می‌خواهم روند را ببینم؟
- می‌خواهم سهم هر گروه را ببینم؟
- می‌خواهم رابطه دو متغیر را بررسی کنم؟
- می‌خواهم توزیع داده را بفهمم؟

پاسخ همین سؤال تا حد زیادی نوع نمودار را مشخص می‌کند.

---

## 2. ساخت اولین نمودار

یک جدول ساده بسازید:

| Month | Revenue |
|---|---:|
| Jan | 120 |
| Feb | 138 |
| Mar | 126 |
| Apr | 154 |
| May | 171 |

محدوده را انتخاب کنید و از مسیر:

```text
Insert → Charts
```

نوع نمودار را انتخاب کنید.

Excel یک Chart ایجاد می‌کند که اجزایی مانند عنوان، محور افقی، محور عمودی و Data Series دارد.

---

## 3. اجزای مهم نمودار

### Chart Title
عنوان باید روشن کند نمودار چه چیزی را نشان می‌دهد.

### Axis
محور افقی (`X`) و محور عمودی (`Y`) بسته به نوع Chart نقش‌های متفاوتی دارند.

### Data Series
هر مجموعه مقادیر که در نمودار به شکل یک گروه یا خط مستقل نمایش داده می‌شود.

### Legend
اگر بیش از یک Series داشته باشیم، Legend توضیح می‌دهد هر رنگ/سری مربوط به چه گروهی است.

### Data Labels
می‌توان مقدار دقیق نقاط را کنار آن‌ها نمایش داد؛ اما برای تعداد زیاد داده‌ها، شلوغی ایجاد می‌کند.

---

## 4. Switch Row/Column

گاهی Excel داده را آن‌طور که انتظار داریم تفسیر نمی‌کند.

مثلاً ممکن است به‌جای اینکه ماه‌ها روی محور X باشند، نام شعبه‌ها را روی محور قرار دهد.

در این حالت گزینه:

```text
Chart Design → Switch Row/Column
```

می‌تواند برداشت Excel از ساختار داده را عوض کند.

---

## 5. آماده‌سازی داده قبل از Visualization

نمودار خوب از داده خوب می‌آید.

قبل از ساخت Chart بررسی کنید:

- Headerها واضح باشند.
- داده‌ها نوع درستی داشته باشند.
- Missing Valueها شناخته شده باشند.
- Duplicate یا رکورد اشتباه وجود نداشته باشد.
- واحد اندازه‌گیری ثابت باشد.
- Outlierهای مهم بررسی شده باشند.

اگر داده خراب باشد، یک نمودار بسیار حرفه‌ای هم می‌تواند نتیجه غلط را زیبا نمایش دهد.

---

## 🧠 یک چارچوب ساده برای انتخاب نمودار

| سؤال | گزینه مناسب اولیه |
|---|---|
| مقایسه چند دسته | Bar / Column |
| روند در زمان | Line |
| سهم از یک کل | Pie / Doughnut در شرایط مناسب |
| رابطه دو متغیر عددی | Scatter |
| سه متغیر عددی | Bubble |
| توزیع یک متغیر | Histogram |
| دو مقیاس/پیام متفاوت | Combo |

این جدول قانون مطلق نیست؛ همیشه Context مهم است.

---

## 🧪 تمرین

برای هر سؤال نوع نمودار مناسب را پیشنهاد دهید:

1. فروش ۱۰ محصول مختلف
2. روند فروش ۱۲ ماه سال
3. سهم کانال‌های بازاریابی از کل فروش
4. رابطه هزینه تبلیغات و فروش
5. توزیع سن مشتریان
6. مقایسه فروش و حاشیه سود که مقیاس یکسانی ندارند

سپس هر شش نمودار را در Excel بسازید و توضیح دهید چرا این نوع Chart را انتخاب کرده‌اید.

---

## ✅ خلاصه

- Visualization بخشی از تحلیل است، نه تزئین فایل.
- نوع Chart باید با سؤال و نوع داده هماهنگ باشد.
- `Switch Row/Column` برای اصلاح برداشت Excel از جهت داده مفید است.
- آماده‌سازی داده قبل از Visualization ضروری است.
