# جلسه ۲ — فرمول‌نویسی و توابع عددی پایه

> **هدف جلسه:** یاد می‌گیریم Excel را از یک جدول ساده به یک محیط محاسباتی تبدیل کنیم؛ یعنی به‌جای وارد کردن نتیجه، رابطه‌ی بین داده‌ها را تعریف کنیم تا Excel محاسبات را برای ما انجام دهد.

---

## ۱. Formula در Excel یعنی چه؟

هر زمانی که بخواهیم بر اساس داده‌های موجود یک محاسبه انجام دهیم، می‌توانیم از **Formula** استفاده کنیم.

فرمول‌ها در Excel با علامت `=` شروع می‌شوند.

مثلاً اگر `A2` تعداد کالا و `B2` قیمت واحد باشد:

```excel
=A2*B2
```

یعنی:

> مقدار A2 را در مقدار B2 ضرب کن.

اگر `A2` برابر 4 و `B2` برابر 275000 باشد، نتیجه `1100000` خواهد بود.

نکته مهم اینجاست که Excel فقط نتیجه را نگه نمی‌دارد؛ رابطه را هم می‌شناسد. بنابراین اگر تعداد یا قیمت را تغییر دهیم، نتیجه هم دوباره محاسبه می‌شود.

---

# ۲. عملگرهای اصلی ریاضی

در Formulaها می‌توان از عملگرهای پایه استفاده کرد:

| عملگر | کاربرد | مثال |
|---|---|---|
| `+` | جمع | `=A1+B1` |
| `-` | تفریق | `=A1-B1` |
| `*` | ضرب | `=A1*B1` |
| `/` | تقسیم | `=A1/B1` |
| `^` | توان | `=A1^2` |

مثلاً:

```excel
=A1^2-2*B1
```

یعنی مربع `A1` را محاسبه کن و دو برابر `B1` را از آن کم کن.

## ترتیب انجام محاسبات

Excel مانند محاسبات معمول ریاضی، ترتیب مشخصی را رعایت می‌کند. به‌صورت ساده:

1. پرانتز
2. توان
3. ضرب و تقسیم
4. جمع و تفریق

مثلاً:

```excel
=5+2*3
```

نتیجه `11` است، نه `21`، چون ضرب قبل از جمع انجام می‌شود.

برای جلوگیری از ابهام، استفاده از پرانتز را عادت کنید:

```excel
=(5+2)*3
```

---

# ۳. Reference به سلول‌ها

به‌جای اینکه عددها را مستقیماً داخل Formula بنویسیم، بهتر است تا حد امکان به Cellها Reference بدهیم.

بد:

```excel
=4*275000
```

بهتر:

```excel
=A2*B2
```

در حالت دوم، Formula به داده‌های واقعی Worksheet متصل است. اگر ورودی عوض شود، خروجی هم تغییر می‌کند.

این موضوع پایه‌ی ساخت مدل‌های Excel است.

---

# ۴. توابع Excel چیستند؟

گاهی Formula ساده برای مسئله ما کافی نیست. Excel مجموعه بزرگی از **Function**های آماده دارد که عملیات مشخصی را انجام می‌دهند.

ساختار کلی بسیاری از توابع شبیه این است:

```excel
=FUNCTION(argument1, argument2, ...)
```

مثلاً:

```excel
=SUM(A2:A10)
```

در اینجا `SUM` نام تابع و `A2:A10` ورودی آن است.

> **Formula و Function یکی نیستند.** Function یک ابزار آماده است؛ Formula می‌تواند از Function، عملگرها، Referenceها یا ترکیبی از آن‌ها استفاده کند.

---

# ۵. SUM — جمع کردن داده‌ها

تابع `SUM` برای محاسبه مجموع استفاده می‌شود.

```excel
=SUM(A2:A11)
```

این فرمول تمام مقادیر از `A2` تا `A11` را با هم جمع می‌کند.

می‌توانیم یک Range دوبعدی هم بدهیم:

```excel
=SUM(B2:E6)
```

در این حالت همه‌ی سلول‌های مستطیلی بین این دو نقطه در محاسبه شرکت می‌کنند.

### کاربرد واقعی

اگر ستون `D` مبلغ سفارش‌ها باشد:

```excel
=SUM(D2:D500)
```

می‌توانیم مجموع فروش ثبت‌شده را سریع به دست بیاوریم.

---

# ۶. PRODUCT — ضرب چند مقدار

تابع `PRODUCT` برای ضرب مقادیر استفاده می‌شود.

```excel
=PRODUCT(A2:A5)
```

مثلاً اگر در `A2:A5` مقادیر `2`، `3`، `4` و `5` باشند، حاصل ضرب همه‌ی آن‌ها محاسبه می‌شود.

البته برای محاسبات معمولی دو سلول، نوشتن `=A2*B2` ساده‌تر است؛ `PRODUCT` وقتی مجموعه‌ای از اعداد را داریم کاربرد بیشتری پیدا می‌کند.

---

# ۷. AVERAGE — میانگین

برای میانگین حسابی از `AVERAGE` استفاده می‌کنیم:

```excel
=AVERAGE(B2:B20)
```

مثلاً برای محاسبه میانگین نمرات، مبلغ سفارش‌ها یا زمان انجام پروژه می‌توان از آن استفاده کرد.

---

# ۸. MIN و MAX — کمینه و بیشینه

`MIN` کوچک‌ترین مقدار و `MAX` بزرگ‌ترین مقدار را برمی‌گرداند.

```excel
=MIN(C2:C50)
=MAX(C2:C50)
```

مثلاً در یک جدول قیمت، با این دو تابع می‌توان ارزان‌ترین و گران‌ترین مقدار را پیدا کرد.

---

# ۹. COUNT — شمارش مقادیر عددی

تابع `COUNT` تعداد سلول‌هایی را می‌شمارد که مقدار عددی دارند.

```excel
=COUNT(B2:B100)
```

این نکته را به خاطر بسپارید:

> `COUNT` به‌طور مشخص برای شمارش **مقادیر عددی** است.

اگر در همان محدوده متن هم داشته باشیم، متن‌ها در `COUNT` شمرده نمی‌شوند.

---

# ۱۰. ROUND — کنترل تعداد اعشار

گاهی نتیجه‌ی محاسبه تعداد زیادی رقم اعشار دارد و برای گزارش نهایی، دقت مشخصی می‌خواهیم.

برای مثال:

```excel
=ROUND(A2,2)
```

مقدار `A2` را تا دو رقم اعشار گرد می‌کند.

مثلاً:

```text
12.34567 → 12.35
```

برای سه رقم اعشار:

```excel
=ROUND(A2,3)
```

---

# ۱۱. POWER و MOD

## POWER

برای محاسبه توان می‌توان از `POWER` هم استفاده کرد:

```excel
=POWER(A2,3)
```

این فرمول مقدار `A2` را به توان ۳ می‌رساند.

برای توان‌های ساده، عملگر `^` نیز کافی است:

```excel
=A2^3
```

---

## MOD

تابع `MOD` باقی‌مانده‌ی تقسیم را برمی‌گرداند.

```excel
=MOD(A2,B2)
```

مثلاً:

```excel
=MOD(17,5)
```

نتیجه `2` خواهد بود.

این تابع برای مسئله‌هایی مثل تشخیص زوج و فرد یا ساخت الگوهای دوره‌ای کاربرد دارد.

مثلاً برای تشخیص زوج بودن یک عدد می‌توان از این منطق استفاده کرد:

```excel
=MOD(A2,2)=0
```

# ۱۲. یک مثال واقعی: جدول فروش

فرض کنید جدول زیر را داریم:

| Product | Quantity | Unit Price | Total |
|---|---:|---:|---:|
| Mouse | 4 | 720000 | ? |
| Keyboard | 2 | 1450000 | ? |
| Headset | 3 | 980000 | ? |

در ستون `Total` می‌نویسیم:

```excel
=B2*C2
```

سپس Formula را برای ردیف‌های دیگر نیز اعمال می‌کنیم.

در پایین جدول می‌توانیم داشته باشیم:

```excel
=SUM(D2:D4)
=AVERAGE(D2:D4)
=MIN(D2:D4)
=MAX(D2:D4)
```

به این ترتیب فقط با چند Formula ساده، از جدول خام به یک Summary اولیه می‌رسیم.

---

# ۱۳. خود Excel می‌تواند Formula را پیشنهاد دهد

وقتی شروع به تایپ Function می‌کنید، Excel معمولاً نام توابع مرتبط را پیشنهاد می‌دهد.

مثلاً با نوشتن:

```text
=SUM
```

می‌توانید Function مربوطه را انتخاب کنید.

پیشنهاد می‌کنم هنگام یادگیری، همیشه Function را کامل تایپ نکنید؛ از پیشنهادهای Excel کمک بگیرید تا کم‌کم نام و ساختار آن‌ها در ذهنتان تثبیت شود.

---

# 🧪 تمرین جلسه

یک Worksheet با نام `Sales` بسازید و جدول زیر را وارد کنید:

| Product | Quantity | Unit Price |
|---|---:|---:|
| Monitor | 3 | 6800000 |
| Keyboard | 5 | 1350000 |
| Mouse | 8 | 620000 |
| Webcam | 2 | 2150000 |
| SSD | 4 | 3900000 |

سپس:

1. ستون `Total Sales` را با Formula بسازید.
2. مجموع فروش را محاسبه کنید.
3. میانگین مبلغ سفارش را به دست آورید.
4. بیشترین و کمترین مبلغ را پیدا کنید.
5. بررسی کنید چند مقدار عددی در ستون `Quantity` ثبت شده است.
6. یکی از قیمت‌ها را تغییر دهید و ببینید کدام نتایج به‌صورت خودکار تغییر می‌کنند.

### چالش
به‌صورت دستی حساب کنید که اگر قیمت SSD ده درصد افزایش پیدا کند، فروش آن چقدر می‌شود. سپس همان مسئله را با Formula در Excel پیاده کنید.

---

# 🧠 نکات کلیدی

> Formulaها با `=` شروع می‌شوند.

> تا حد امکان به جای نوشتن عدد ثابت، به Cellها Reference بدهید.

> `SUM`، `AVERAGE`، `MIN`، `MAX` و `COUNT` از پایه‌ای‌ترین Functionهای عددی هستند.

> `ROUND` برای کنترل تعداد اعشار کاربرد دارد.

> `MOD` باقی‌مانده تقسیم را برمی‌گرداند.

> هدف Formula فقط تولید یک عدد نیست؛ هدف تعریف **رابطه بین داده‌ها**ست.
