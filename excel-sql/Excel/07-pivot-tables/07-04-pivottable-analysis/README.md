# جلسه ۷-۴ — تحلیل داده با PivotTable

## هدف جلسه

در این جلسه PivotTable را از یک ابزار ساخت جدول به یک ابزار پاسخ‌گویی به سؤال‌های تحلیلی تبدیل می‌کنیم.

## Dataset نمونه: مسافران یک سفر دریایی

برای تمرین می‌توانیم از یک Dataset آموزشی درباره مسافران یک کشتی استفاده کنیم. ستون‌هایی مثل `PassengerId`، `Survived`، `Pclass`، `Sex`، `Age`، `Fare` و `Embarked` در آن وجود دارد.

سؤال اصلی ما این است:

> آیا بین ویژگی‌های مسافر و احتمال زنده ماندن رابطه‌ای قابل مشاهده وجود دارد؟

دقت کنید که PivotTable به‌تنهایی «اثبات رابطه» یا «آزمون آماری» انجام نمی‌دهد؛ اما برای **اکتشاف اولیه** بسیار مفید است.

## تحلیل ۱ — وضعیت بقا

ابتدا `Survived` را در Rows قرار دهید و Count of PassengerId را در Values بگذارید.

گزارش تعداد افراد زنده‌مانده و فوت‌شده را نشان می‌دهد.

سپس `Pclass` را به Columns اضافه کنید.

حالا می‌توانیم وضعیت بقا را در کلاس‌های مختلف مقایسه کنیم.

اگر به جای تعداد خام، درصد بخواهیم، از **Show Values As** استفاده می‌کنیم تا مقایسه سهمی انجام شود.

> **درس تحلیلی:** در داده‌هایی با اندازه گروه متفاوت، درصدها معمولاً برای مقایسه منصفانه‌تر از تعداد خام‌اند.

## تحلیل ۲ — جنسیت

`Sex` را به Columns ببرید.

حالا گزارش نشان می‌دهد توزیع بقا در گروه‌های جنسیتی چگونه بوده است.

در این مرحله فقط می‌گوییم:

> «در داده مشاهده می‌کنیم که گروه‌ها الگوهای متفاوتی دارند.»

اما هنوز نمی‌گوییم یک ویژگی «علت» نتیجه بوده است. برای نتیجه‌گیری دقیق‌تر به روش‌های آماری نیاز داریم.

## تحلیل ۳ — بندر سوار شدن

`Embarked` را به Columns اضافه کنید.

اگر اختلاف‌ها کمتر از تحلیل‌های قبلی باشند، یک نکته جالب به دست آورده‌ایم: **همه متغیرها به یک اندازه تفکیک‌کننده نیستند.**

PivotTable کمک می‌کند سریع بفهمیم کدام برش‌های داده ارزش بررسی بیشتر دارند.

## تحلیل ۴ — تبدیل یک متغیر عددی به گروه

سن یک متغیر عددی پیوسته است و اگر آن را مستقیم در Rows قرار دهیم ممکن است گزارش شلوغ شود.

یکی از راه‌ها ساختن یک ستون کمکی برای گروه سنی است. مثلاً:

```excel
=IFS(
  E2<13,"Child",
  E2<20,"Teen",
  E2<35,"Young Adult",
  E2<55,"Adult",
  TRUE,"Senior"
)
```

> **نکته مهم:** Missing Value را نباید خودکار در گروه اول قرار دهیم. برای داده‌های خالی بهتر است یک دسته جدا مثل `Unknown` داشته باشیم.

مثلاً:

```excel
=IF(E2="","Unknown",IFS(E2<13,"Child",E2<20,"Teen",E2<35,"Young Adult",E2<55,"Adult",TRUE,"Senior"))
```

بعد گروه سنی را در Pivot قرار دهید و آن را با `Survived` مقایسه کنید.

## تحلیل ۵ — اندازه خانواده

اگر ستون‌های `SibSp` و `Parch` را داشته باشیم، می‌توانیم یک ویژگی جدید بسازیم:

```excel
=SibSp + Parch + 1
```

عدد ۱ نماینده خود مسافر است.

سپس می‌توانیم گروه‌های ساده‌ای بسازیم:

```text
1 → تنها
2–4 → خانواده کوچک
5+ → خانواده بزرگ
```

PivotTable این امکان را می‌دهد که این گروه‌ها را با سایر متغیرها مقایسه کنیم.

## از Pivot چه نتیجه‌ای بگیریم؟

PivotTable برای **EDA (Exploratory Data Analysis)** عالی است. ما با آن می‌توانیم:

- گروه‌های متفاوت را مقایسه کنیم؛
- الگوهای اولیه را پیدا کنیم؛
- سؤال‌های تازه برای تحلیل بسازیم؛
- داده را از زوایای مختلف ببینیم.

اما توجه کنید:

> مشاهده اختلاف در PivotTable به معنی وجود رابطه علت و معلولی نیست.

مثلاً اگر دو گروه نرخ بقا متفاوتی داشته باشند، هنوز نمی‌توانیم بگوییم ویژگی گروه اول دلیل این اختلاف بوده است.

## یک تکنیک مهم: Counts در برابر Percentages

فرض کنید گروه A، ۸۰ نفر و گروه B، ۲۰ نفر دارد.

اگر ۴۰ نفر از A و ۱۲ نفر از B زنده مانده باشند:

```text
A → 40 / 80 = 50%
B → 12 / 20 = 60%
```

تعداد خام می‌گوید A افراد بیشتری داشته، اما نرخ نشان می‌دهد نسبت بقا در B بیشتر بوده است.

بنابراین در تحلیل گروه‌ها همیشه بپرسید:

> «تعداد را مقایسه می‌کنم یا نرخ/سهم را؟»

## تمرین کلاسی

با Dataset آموزشی:

1. تعداد رکوردها را بر اساس `Pclass` بسازید.
2. نرخ `Survived` را برای هر `Pclass` محاسبه کنید.
3. همین تحلیل را بر اساس `Sex` تکرار کنید.
4. یک گروه سنی بسازید و بقا را در گروه‌ها مقایسه کنید.
5. یک سؤال جدید خودتان طراحی و با PivotTable بررسی کنید.
