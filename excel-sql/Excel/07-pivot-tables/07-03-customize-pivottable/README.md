# جلسه ۷-۳ — شخصی‌سازی و تنظیم محاسبات PivotTable

## هدف جلسه

PivotTable بعد از ساخته شدن فقط یک گزارش خام نیست. در این جلسه یاد می‌گیریم نام فیلدها، نوع محاسبه، نحوه نمایش Totalها و ظاهر گزارش را متناسب با نیازمان تغییر دهیم.

## تغییر عنوان و نام فیلدها

PivotTable برای نام‌گذاری از Headerهای داده منبع استفاده می‌کند. این نام‌ها همیشه برای گزارش نهایی مناسب نیستند.

مثلاً به‌جای:

```text
Sum of Amount
```

می‌توانیم عنوانی مثل:

```text
Total Sales
```

داشته باشیم.

برای تغییرات ساده می‌توان مستقیماً عنوان مناسب را وارد کرد؛ برای تغییر منطق محاسبه از **Value Field Settings** استفاده می‌کنیم.

## Value Field Settings

روی یکی از مقادیر Pivot راست‌کلیک کنید و **Value Field Settings** را باز کنید.

دو بخش مهم در اختیار داریم:

### Summarize Values By
مشخص می‌کند داده چگونه خلاصه شود:

- Sum
- Count
- Average
- Max
- Min
- و گزینه‌های دیگر

### Show Values As
علاوه بر مقدار خام، می‌توان همان مقدار را به شکل درصد، اختلاف یا رتبه هم نمایش داد. این بخش هنگام ساخت گزارش‌های مقایسه‌ای بسیار کاربردی است.

برای مثال اگر بخواهیم «سهم هر محصول از کل فروش» را ببینیم، یک Sum ساده کافی نیست و بهتر است از گزینه‌های **Show Values As → % of Grand Total** استفاده کنیم.

## Row Labels و Column Labels

عنوان‌های سطر و ستون را می‌توان برای گزارش خواناتر اصلاح کرد. همچنین با تغییر ترتیب فیلدها، ساختار گزارش عوض می‌شود.

## Grand Total و Subtotal

PivotTable می‌تواند جمع کل و در برخی چیدمان‌ها Subtotal گروه‌ها را نمایش دهد.

برای گزارش مدیریتی لازم نیست همیشه همه Totalها نمایش داده شوند. از تب **Design** می‌توان نمایش Subtotal و Grand Total را کنترل کرد.

## طراحی گزارش

تب **PivotTable Design** امکاناتی برای کنترل ظاهر دارد، مانند:

- Report Layout
- Blank Rows
- Banded Rows
- Banded Columns
- PivotTable Styles
- Subtotals
- Grand Totals

یکی از انتخاب‌های مفید، تغییر Report Layout به **Tabular Form** است؛ این حالت در بعضی گزارش‌ها خروجی نزدیک‌تری به یک جدول معمولی ایجاد می‌کند.

## چرا ظاهر مهم است؟

PivotTable در تحلیل اکتشافی خیلی مفید است، اما اگر قرار باشد گزارش را به مدیر یا مشتری تحویل دهیم، خوانایی مهم است. عنوان مناسب، اعداد با فرمت درست و حذف اطلاعات بصری اضافی باعث می‌شود نتیجه سریع‌تر فهمیده شود.

> PivotTable خوب فقط «درست محاسبه نمی‌کند»؛ باید بتوان نتیجه آن را هم راحت خواند.

## تمرین

یک PivotTable از فروش شعب بسازید و آن را در دو نسخه ارائه کنید:

1. گزارش تحلیلی خام برای خودتان.
2. گزارش مدیریتی تمیز با عنوان‌های مناسب، Number Format و Grand Total کنترل‌شده.

### Challenge
دو Value از `Amount` اضافه کنید: یکی Sum و یکی Average. سپس برای Sum، نمایش را به درصد کل تغییر دهید و هر دو معیار را با عنوان مناسب در گزارش قرار دهید.
