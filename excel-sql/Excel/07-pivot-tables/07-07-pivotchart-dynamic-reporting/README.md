# جلسه ۷-۷ — PivotChart و گزارش‌دهی پویا

## PivotChart چیست؟

PivotChart نموداری است که مستقیماً با یک PivotTable ارتباط دارد. بنابراین وقتی Pivot فیلتر یا بازآرایی می‌شود، نمودار هم متناسب با آن تغییر می‌کند.

این اتصال، PivotChart را برای گزارش‌های تعاملی بسیار مناسب می‌کند.

## ساخت PivotChart

1. داخل PivotTable کلیک کنید.
2. از مسیر **Insert → PivotChart** استفاده کنید.
3. نوع نمودار را انتخاب کنید.
4. نمودار ساخته‌شده را مانند سایر Chartهای Excel شخصی‌سازی کنید.

انتخاب نوع نمودار باید تابع سؤال باشد:

| سؤال | انتخاب مناسب |
|---|---|
| مقایسه فروش شعب | Column / Bar |
| روند فروش در طول زمان | Line |
| سهم نسبی چند دسته | Pie در شرایط مناسب |
| مقایسه رابطه دو متغیر | Scatter، معمولاً خارج از PivotChart |

## تعامل با فیلترها

اگر PivotTable یک Slicer یا Timeline داشته باشد، این کنترل‌ها می‌توانند روی PivotChart هم اثر بگذارند.

مثلاً:

```text
Region Slicer
      ↓
   PivotTable
      ↓
   PivotChart
```

کاربر منطقه را انتخاب می‌کند و هم جدول و هم نمودار متناسب با انتخاب تغییر می‌کنند.

## گزارش‌دهی پویا چیست؟

گزارش پویا گزارشی است که با تغییر داده یا انتخاب کاربر، نتیجه آن بدون ساخت دستی یک گزارش جدید تغییر کند.

یک گزارش می‌تواند از چند جزء کنار هم ساخته شود:

```text
Data Source
    ↓
Cleaning / Transformation
    ↓
PivotTable
    ↓
Slicer / Timeline
    ↓
PivotChart
    ↓
KPI / Final Report
```

## مثال: داشبورد فروش

فرض کنید سه PivotTable داریم:

- فروش بر اساس ماه
- فروش بر اساس محصول
- تعداد سفارش بر اساس منطقه

و یک Slicer به نام `Region`.

اگر کاربر `East` را انتخاب کند، هر سه گزارش باید فقط داده‌های همان منطقه را نشان دهند.

این همان تجربه‌ای است که در داشبوردهای مدیریتی انتظار داریم.

## خطاهای رایج در گزارش‌های پویا

### ۱. فیلترهای جداگانه
اگر برای هر نمودار یک فیلتر مستقل ساخته شود، ممکن است کاربر تصور کند همه نمودارها یک وضعیت یکسان دارند در حالی که ندارند.

### ۲. عنوان نامشخص
نموداری که عنوانش فقط «Sales» است، بعد از اعمال فیلتر ممکن است مشخص نکند فروش مربوط به کدام منطقه یا دوره است.

### ۳. نمایش بیش از حد اطلاعات
تعامل بیشتر همیشه به معنی گزارش بهتر نیست. داشبورد باید چند سؤال مشخص را سریع پاسخ دهد.

### ۴. مخلوط کردن معیارهای نامتجانس
مقایسه یک مبلغ بزرگ با درصد کوچک در یک محور می‌تواند گمراه‌کننده باشد؛ در چنین حالتی Combo Chart یا محور ثانویه ممکن است لازم شود.

## تمرین نهایی فصل

یک فایل فروش انتخاب کنید و یک گزارش کوچک بسازید که شامل موارد زیر باشد:

- یک PivotTable برای فروش محصولات
- یک PivotTable برای فروش ماهانه
- یک PivotChart
- یک Slicer برای Region
- یک Timeline برای Date
- یک KPI برای Total Sales

سپس با تغییر Region بررسی کنید آیا تمام اجزای گزارش مطابق انتظار تغییر می‌کنند.

### Challenge
گزارش را طوری طراحی کنید که بدون توضیح شفاهی، کاربر بفهمد:

1. چه چیزی اندازه‌گیری شده است؟
2. مربوط به چه بازه زمانی است؟
3. چه فیلتری فعال است؟
4. کدام گروه عملکرد بهتری داشته است؟

## جمع‌بندی فصل ۷

در این فصل یاد گرفتیم که چگونه از یک Dataset خام، گزارش تحلیلی بسازیم. ابتدا PivotTable را به‌عنوان ابزار خلاصه‌سازی شناختیم، سپس Rows، Columns، Values و Filters را تنظیم کردیم. بعد سراغ محاسبات، Slicer، Timeline، GETPIVOTDATA و Drill Down رفتیم و در نهایت PivotChart و گزارش‌دهی پویا را اضافه کردیم.

در فصل بعد، از همین قطعات برای ساخت **Dashboardهای حرفه‌ای و تعاملی** استفاده خواهیم کرد.
