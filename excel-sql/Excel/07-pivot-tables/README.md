## پیش‌نیاز

قبل از شروع این فصل بهتر است با ساختار جدول، Filter، Sort و اصول اولیه فرمول‌نویسی Excel راحت باشید.

## ایده اصلی فصل

در تحلیل داده معمولاً با چنین مسئله‌ای روبه‌رو هستیم:

```text
Raw Data
   ↓
سؤال کسب‌وکار
   ↓
گروه‌بندی و خلاصه‌سازی
   ↓
PivotTable
   ↓
فیلتر و مقایسه
   ↓
PivotChart / Report
```

PivotTable قرار نیست داده خام را جایگزین کند؛ قرار است از روی آن یک **نمای خلاصه و تحلیلی** بسازد.
