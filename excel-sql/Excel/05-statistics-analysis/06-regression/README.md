# جلسه ۶ — Regression و مدل‌سازی ساده

## Regression چه مسئله‌ای را حل می‌کند؟

گاهی فقط نمی‌خواهیم بگوییم دو متغیر رابطه دارند؛ می‌خواهیم یک رابطه ریاضی تقریبی بسازیم و از آن برای **توضیح یا پیش‌بینی** استفاده کنیم.

مثلاً:

> آیا با توجه به هزینه تبلیغات می‌توان مقدار فروش را تخمین زد؟

یکی از روش‌های پایه برای این کار Linear Regression است.

---

## 1. ایده Linear Regression

در ساده‌ترین حالت، مدل به شکل زیر است:

```text
y = a + bx
```

- `y` متغیر هدف
- `x` متغیر توضیحی
- `a` عرض از مبدأ
- `b` شیب

اگر `b` مثبت باشد، در مدل با افزایش x، y نیز تمایل به افزایش دارد.

---

## 2. ساخت Regression در Excel

یکی از راه‌ها استفاده از ابزار Data Analysis و گزینه Regression است.

مسیر معمول:

```text
Data → Data Analysis → Regression
```

در این بخش باید محدوده `Y` و `X` را مشخص کنیم.

---

## 3. R² چیست؟

`R Square` معیاری است که در یک مدل رگرسیون خطی نشان می‌دهد چه مقدار از تغییرات متغیر هدف توسط متغیرهای موجود در مدل توضیح داده می‌شود.

مثلاً اگر `R² = 0.72` باشد، می‌توان گفت در این مدل و روی این داده، حدود ۷۲٪ از تغییرات Y با Xهای موجود توضیح داده می‌شود.

اما این عدد به‌تنهایی نشانه «خوب بودن قطعی مدل» نیست.

---

## 4. Residual یا خطای مدل

مدل برای هر مشاهده یک مقدار پیش‌بینی‌شده می‌سازد. اختلاف بین مقدار واقعی و مقدار پیش‌بینی‌شده را **Residual** می‌نامیم.

```text
Residual = Actual - Predicted
```

بررسی Residualها می‌تواند آشکار کند که مدل الگوی مناسبی ندارد یا بعضی مشاهدات غیرعادی‌اند.

---

## 5. رابطه Regression و Correlation

در یک مدل خطی ساده، Correlation و Regression با هم ارتباط نزدیکی دارند؛ اما یکسان نیستند.

Correlation بیشتر درباره شدت و جهت رابطه خطی صحبت می‌کند، در حالی‌که Regression یک مدل می‌سازد که می‌توان از آن برای تخمین Y بر اساس X استفاده کرد.

---

## 6. مراقب پیش‌بینی خارج از محدوده باشیم

فرض کنید داده‌های ما برای تبلیغات بین ۱۰ تا ۱۰۰ میلیون هستند. ساخت یک مدل بر اساس همین محدوده و سپس پیش‌بینی فروش برای هزینه تبلیغات ۵۰۰ میلیون می‌تواند خطرناک باشد.

این حالت **Extrapolation** است و باید با احتیاط با آن برخورد کرد.

---

## 7. Regression به معنی علت و معلول نیست

حتی اگر یک مدل Regression رابطه قوی نشان دهد، هنوز نمی‌توان بدون طراحی مناسب مطالعه ادعا کرد X علت Y است.

وجود متغیرهای مخفی، سوگیری نمونه و ساختار داده می‌تواند باعث رابطه ظاهری شود.

---

## 🧪 تمرین

یک Dataset از حداقل ۳۰ ماه/کمپین بسازید:

`Advertising Spend | Sales`

1. Scatter Chart رسم کنید.
2. Correlation را حساب کنید.
3. Linear Regression بسازید.
4. شیب و Intercept را بررسی کنید.
5. R² را تفسیر کنید.
6. چند Residual را محاسبه و بررسی کنید.
7. توضیح دهید مدل شما برای چه محدوده‌ای معتبرتر است.

---

## ✅ خلاصه

- Regression یک رابطه مدل‌سازی‌شده بین متغیرها ایجاد می‌کند.
- در Linear Regression ساده مدل به شکل `y = a + bx` است.
- R² میزان توضیح‌دادن تغییرات Y توسط مدل را خلاصه می‌کند.
- Residual اختلاف مقدار واقعی و پیش‌بینی است.
- Regression و Correlation مفاهیم مرتبط ولی متفاوت‌اند.
- پیش‌بینی خارج از محدوده داده و برداشت علت‌ومعلولی نیازمند احتیاط جدی است.
