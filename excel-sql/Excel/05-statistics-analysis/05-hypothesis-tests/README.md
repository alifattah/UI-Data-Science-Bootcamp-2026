# جلسه ۵ — آزمون‌های آماری در Excel

## چرا آزمون آماری؟

فرض کنید میانگین فروش دو شعبه با هم فرق دارد. آیا واقعاً عملکردشان متفاوت است یا این اختلاف می‌تواند صرفاً ناشی از نوسان تصادفی نمونه باشد؟

اینجا وارد دنیای **Hypothesis Testing** می‌شویم.

در این جلسه با سه خانواده مهم آشنا می‌شویم:

- T-Test
- ANOVA
- Chi-Square

هدف، حفظ کردن دکمه‌های Excel نیست؛ باید بفهمیم هر آزمون چه سؤال آماری‌ای را پاسخ می‌دهد.

---

## 1. منطق کلی آزمون فرض

به‌صورت ساده، یک آزمون آماری معمولاً این روند را دارد:

```text
سؤال
 ↓
فرض صفر و فرض مقابل
 ↓
انتخاب آزمون مناسب
 ↓
محاسبه آماره / p-value
 ↓
تفسیر نتیجه
```

یکی از مفاهیم کلیدی `p-value` است. در یک آستانه معناداری مثل `0.05`، اگر p-value به‌اندازه کافی کوچک باشد، شواهدی علیه فرض صفر داریم.

> توجه: «معنادار نبودن» به معنی «اثبات برابر بودن» نیست.

---

## 2. T-Test

وقتی می‌خواهیم میانگین دو گروه را مقایسه کنیم، T-Test یکی از گزینه‌های رایج است.

### مثال

فرض کنید زمان پاسخ‌گویی دو تیم پشتیبانی را داریم:

```text
Team A → 14, 16, 12, 15, 13, ...
Team B → 18, 17, 20, 16, 19, ...
```

سؤال:

> آیا میانگین زمان پاسخ دو تیم تفاوت معناداری دارد؟

در Excel می‌توان از ابزارهای Data Analysis برای T-Test استفاده کرد یا بر اساس نوع طراحی مسئله از توابع مربوط به آزمون استفاده کرد.

نوع آزمون مهم است؛ مثلاً دو نمونه مستقل با داده‌های paired یکی نیستند.

---

## 3. ANOVA

اگر بخواهیم میانگین **بیش از دو گروه** را مقایسه کنیم، به‌جای اجرای چند T-Test معمولاً سراغ ANOVA می‌رویم.

مثلاً سه شعبه داریم:

```text
Branch A
Branch B
Branch C
```

و می‌خواهیم بررسی کنیم آیا میانگین فروش آن‌ها متفاوت است یا نه.

ANOVA ابتدا بررسی می‌کند آیا شواهدی از تفاوت بین گروه‌ها وجود دارد. اگر نتیجه معنادار باشد، برای فهمیدن اینکه دقیقاً کدام گروه‌ها متفاوت‌اند به تحلیل‌های تکمیلی نیاز داریم.

> **نکته:** یک ANOVA معنادار لزوماً نمی‌گوید همه گروه‌ها با هم تفاوت دارند.

---

## 4. Chi-Square

Chi-Square بیشتر برای بررسی رابطه بین متغیرهای دسته‌ای (`Categorical`) استفاده می‌شود.

مثلاً:

> آیا نوع دستگاه استفاده‌شده توسط مشتری با احتمال خرید اشتراک ارتباط دارد؟

جدول:

| Device | Purchased | Not Purchased |
|---|---:|---:|
| Mobile | 120 | 80 |
| Desktop | 90 | 110 |
| Tablet | 25 | 35 |

در اینجا متغیرها دسته‌ای هستند و می‌توانیم از آزمون Chi-Square برای بررسی استقلال آن‌ها استفاده کنیم.

---

## 5. انتخاب آزمون مناسب

| سؤال | آزمون محتمل |
|---|---|
| مقایسه میانگین دو گروه | T-Test |
| مقایسه میانگین چند گروه | ANOVA |
| بررسی رابطه بین متغیرهای دسته‌ای | Chi-Square |

این جدول فقط یک راهنمای شروع است. طراحی مطالعه، استقلال نمونه‌ها، توزیع داده‌ها و فرض‌های آماری نیز باید بررسی شوند.

---

## 6. Analysis ToolPak

برای برخی تحلیل‌ها می‌توان از `Data Analysis` در Excel استفاده کرد. اگر این بخش در Excel شما فعال نیست، باید Add-in مربوطه را فعال کنید.

مسیر معمول:

```text
Data → Data Analysis
```

در این محیط ابزارهایی برای آزمون‌های آماری و Regression وجود دارد.

---

## 7. خطاهای رایج در تفسیر

### اشتباه ۱ — p-value کوچک یعنی اثر بزرگ
خیر. p-value درباره شواهد آماری است؛ اندازه اثر مفهوم دیگری است.

### اشتباه ۲ — p-value بزرگ یعنی دو گروه کاملاً یکسان‌اند
خیر. ممکن است داده برای کشف تفاوت کافی نباشد.

### اشتباه ۳ — هر اختلاف میانگینی نیاز به T-Test دارد
نه. باید ابتدا نوع داده و سؤال را مشخص کنیم.

### اشتباه ۴ — بدون بررسی داده آزمون اجرا کنیم
Outlier، وابستگی داده‌ها، Missing Value و طراحی نمونه می‌توانند نتیجه را تحت تأثیر قرار دهند.

---

## 🧪 تمرین

یک Dataset شامل فروش سه شعبه طراحی کنید.

1. میانگین هر شعبه را محاسبه کنید.
2. نمودار مناسبی برای مقایسه رسم کنید.
3. با ANOVA بررسی کنید آیا تفاوت معناداری بین میانگین‌ها وجود دارد.
4. در یک Dataset جدا، دو گروه فروش ایجاد کرده و یک T-Test مناسب اجرا کنید.
5. یک جدول دوطرفه برای «نوع دستگاه × خرید اشتراک» بسازید و Chi-Square را تمرین کنید.
6. نتیجه هر آزمون را با یک جمله ساده و بدون اغراق بنویسید.

---

## ✅ خلاصه

- آزمون آماری برای پاسخ به سؤال درباره داده و عدم‌قطعیت است.
- T-Test برای مقایسه دو گروه کاربرد دارد.
- ANOVA برای مقایسه میانگین چند گروه به کار می‌رود.
- Chi-Square برای مسائل دسته‌ای و بررسی استقلال/ارتباط مناسب است.
- p-value باید در کنار سؤال، فرض‌های آزمون و اندازه اثر تفسیر شود.
