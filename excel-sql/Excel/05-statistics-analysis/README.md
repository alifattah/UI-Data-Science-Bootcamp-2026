# فصل ۵ — آمار و تحلیل‌های پیشرفته در Excel

> در این فصل Excel را از یک ابزار محاسباتی به یک ابزار تحلیل آماری تبدیل می‌کنیم. هدف فقط اجرای Functionها نیست؛ باید یاد بگیریم خروجی آماری چه چیزی می‌گوید، چه چیزی نمی‌گوید و در چه شرایطی قابل اعتماد است.

## اهداف فصل

- شناخت شاخص‌های مرکزی و پراکندگی
- محاسبه Percentile و Quartile
- بررسی Correlation و تفسیر صحیح آن
- آشنایی با T-Test، ANOVA و Chi-Square در Excel
- آشنایی با Regression و شاخص‌هایی مثل R²
- درک محدودیت‌های تحلیل آماری در یک Spreadsheet

## مسیر جلسات

| جلسه | عنوان | خروجی |
|---|---|---|
| 01 | شاخص‌های مرکزی | Mean، Median، Mode و مقایسه آن‌ها |
| 02 | پراکندگی داده | Variance، Standard Deviation و انتخاب P/S |
| 03 | Percentile و Quartile | تحلیل توزیع و موقعیت داده |
| 04 | Correlation | اندازه‌گیری و تفسیر رابطه بین متغیرها |
| 05 | آزمون‌های آماری در Excel | T-Test، ANOVA، Chi-Square |
| 06 | Regression و مدل‌سازی | مدل خطی، ضرایب، R²، خطا و پیش‌بینی |
| 07 | تمرین تحلیلی | یک سناریوی کامل از سؤال تا نتیجه |

> **نکته:** در این فصل بین «محاسبه یک شاخص» و «تفسیر آماری آن» تفاوت جدی می‌گذاریم.
