# جلسه ۸-۲ — طراحی یک Dashboard حرفه‌ای

## هدف جلسه

قبل از اضافه کردن Chart و Slicer، باید بتوانیم صفحه داشبورد را درست طراحی کنیم. ظاهر خوب به‌تنهایی کافی نیست؛ چیدمان باید به کاربر کمک کند سریع‌تر سؤال‌های مهم را پاسخ دهد.

## از کاغذ شروع کنیم

یکی از بهترین روش‌ها این است که قبل از ساخت داشبورد، Layout را روی کاغذ یا یک صفحه سفید طراحی کنیم.

مثلاً:

```text
┌──────────────────────────────────────────────┐
│              SALES DASHBOARD                 │
├───────────┬───────────┬───────────┬──────────┤
│ Revenue   │ Orders    │ Avg Order │ Growth   │
├───────────────────────┬──────────────────────┤
│   Monthly Sales       │ Sales by Region      │
│       Chart           │       Chart          │
├───────────────────────┼──────────────────────┤
│ Top Products          │ Detail / Notes       │
└───────────────────────┴──────────────────────┘
```

هدف چنین طرحی این است که قبل از درگیر شدن با ابزار Excel، جای هر جزء مشخص باشد.

## سلسله‌مراتب اطلاعات

همه اطلاعات اهمیت یکسان ندارند.

### سطح ۱ — KPI
عددهای اصلی در بالاترین قسمت قرار می‌گیرند.

### سطح ۲ — روند و مقایسه
نمودارهایی که وضعیت و تغییرات را نشان می‌دهند.

### سطح ۳ — جزئیات
جدول یا نموداری که برای بررسی بیشتر در نظر گرفته شده است.

### سطح ۴ — Interaction
Slicer، Timeline یا کنترل‌های دیگر.

## انتخاب نمودار بر اساس سؤال

| هدف | نمودار مناسب |
|---|---|
| مقایسه چند گروه | Bar / Column |
| روند زمانی | Line |
| رابطه دو متغیر | Scatter |
| توزیع داده | Histogram |
| ترکیب دو معیار متفاوت | Combo |
| سهم از کل در تعداد دسته محدود | Pie / Doughnut با احتیاط |

> انتخاب نمودار باید از سؤال شروع شود، نه از اینکه «این نمودار قشنگ‌تر است».

## رنگ‌ها

در Dashboard بهتر است رنگ‌ها نقش داشته باشند:

- یک رنگ اصلی برای ساخت هویت بصری
- یک رنگ هشدار برای وضعیت نامطلوب
- یک رنگ تأکید برای موارد مهم

تعداد رنگ‌های زیاد معمولاً خوانایی را کم می‌کند.

## متن و عنوان

عنوان نمودار باید قابل فهم باشد.

ضعیف:

```text
Sales
```

بهتر:

```text
Monthly Revenue — Last 12 Months
```

و اگر فیلتر فعال است، در صورت امکان آن را در متن یا بخش فیلتر واضح نگه دارید.

## حذف شلوغی

خطوط اضافی Gridline، Legendهای بی‌مصرف، Decimalهای غیرضروری و Data Labelهای زیاد می‌توانند داشبورد را شلوغ کنند.

اصل ساده:

> هر چیزی که به فهم پیام کمک نمی‌کند، نامزد حذف شدن است.

## KPI Card

یکی از اجزای رایج داشبورد، کارت KPI است:

```text
TOTAL SALES
₺ 248.6M
+12.4% vs Last Month
```

این کارت باید سه چیز را سریع روشن کند:

1. چه چیزی؟
2. مقدار فعلی چقدر است؟
3. نسبت به معیار قبلی چه وضعیتی دارد؟

## تمرین

طرح قبلی را در Excel پیاده کنید، اما هنوز سراغ پیچیدگی نروید. فقط جای KPI، نمودارها و فیلترها را مشخص کنید.

### Challenge
دو Layout متفاوت برای یک Dashboard فروش طراحی کنید و توضیح دهید چرا یکی از آن‌ها برای مدیرعامل مناسب‌تر است.
