# جلسه ۸-۳ — گزارش‌های پویا با Drop-down و Dynamic Range

## هدف جلسه

در این جلسه یک گزارش می‌سازیم که کاربر بتواند یک گزینه انتخاب کند و خروجی گزارش بدون ورود دوباره داده یا ساخت گزارش تازه، تغییر کند.

## Drop-down فقط برای Data Validation نیست

در فصل‌های قبل از Drop-down برای کنترل ورودی استفاده کردیم. اینجا از همان ایده برای **تعامل با گزارش** استفاده می‌کنیم.

فرض کنید یک گزارش فروش داریم و کاربر باید یکی از مناطق را انتخاب کند:

```text
[ North ▼ ]
```

اگر `North` انتخاب شود، نمودار و KPIهای صفحه فروش شمال را نمایش می‌دهند؛ با انتخاب `South` همان اجزا به‌روز می‌شوند.

## ساخت Drop-down

یک فهرست از گزینه‌ها در یک محدوده قرار دهید:

```text
North
South
East
West
```

سپس یک Cell به نام مثلاً `B2` را انتخاب کنید و از مسیر **Data → Data Validation → List** این محدوده را به‌عنوان Source معرفی کنید.

اکنون `B2` نقش انتخاب‌گر را دارد.

## اتصال Drop-down به Formula

فرض کنید ستون‌های `Region` و `Revenue` در جدول فروش داریم.

می‌توانیم یک بخش گزارش بسازیم که بر اساس مقدار `B2` فقط اطلاعات منطقه انتخاب‌شده را نشان دهد.

در Excelهای جدید می‌توان از `FILTER` استفاده کرد:

```excel
=FILTER(A2:E500,B2:B500=$H$2,"No data")
```

در این مثال:

- `A2:E500` داده خروجی است.
- `B2:B500=$H$2` شرط فیلتر است.
- اگر داده‌ای وجود نداشته باشد، عبارت `No data` نمایش داده می‌شود.

اگر نسخه Excel شما `FILTER` نداشته باشد، می‌توان با روش‌های دیگر مانند Pivot، Advanced Filter یا فرمول‌های قدیمی‌تر این ایده را پیاده کرد.

## Dynamic Range چیست؟

یک Range ثابت مثل:

```text
A2:A100
```

با اضافه شدن رکورد ۱۰۱ دیگر آن داده جدید را شامل نمی‌شود.

در گزارش‌های پویا بهتر است منبع داده طوری باشد که با تغییر Dataset، محدوده نیز رشد یا کوچک شود.

یکی از بهترین راه‌ها در Excel، تبدیل Dataset به **Table** است.

مثلاً جدول را `SalesData` نام‌گذاری کنید. با اضافه شدن یک رکورد جدید، جدول به‌صورت خودکار گسترش می‌یابد و فرمول‌ها و نمودارهایی که به ساختار جدول متصل‌اند، راحت‌تر به‌روز می‌شوند.

## یک معماری ساده

```text
Raw Sales Table
      ↓
Selected Region (Drop-down)
      ↓
Filtered / Calculated Data
      ↓
KPI + Chart
```

این معماری پایه بسیاری از گزارش‌های تعاملی است.

## مثال: انتخاب KPI

فرض کنید کاربر از بین سه معیار انتخاب کند:

```text
Revenue
Orders
Profit
```

و سلول `H2` انتخاب او را نگه دارد.

سپس می‌توانیم با `SWITCH` مشخص کنیم چه مقداری نمایش داده شود:

```excel
=SWITCH(H2,
"Revenue",SUM(SalesData[Revenue]),
"Orders",SUM(SalesData[Orders]),
"Profit",SUM(SalesData[Profit]),
0)
```

حالا یک Cell می‌تواند با انتخاب کاربر KPI متفاوتی نشان دهد.

## تمرین

یک گزارش فروش بسازید که:

- یک Drop-down برای Region داشته باشد.
- با انتخاب Region، جدول گزارش فیلتر شود.
- Total Revenue و Average Order Value برای همان Region نمایش داده شود.
- نمودار گزارش نیز بر اساس انتخاب تغییر کند.

### Challenge
یک Drop-down دوم برای انتخاب Metric بسازید و اجازه دهید کاربر بین Revenue، Orders و Profit جابه‌جا شود.
