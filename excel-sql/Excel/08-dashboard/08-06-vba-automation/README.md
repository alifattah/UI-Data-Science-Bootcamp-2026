# جلسه ۸-۶ — VBA و اتوماسیون ساده در Dashboard

## هدف جلسه

گاهی تعامل موردنیاز داشبورد فقط با Formula، Pivot و Slicer حل نمی‌شود. در چنین مواقعی می‌توان از Macro و VBA برای خودکارسازی کارهای تکراری یا اجرای Actionهای مشخص استفاده کرد.

> این جلسه مقدمه‌ای برای اتوماسیون است؛ هدف آن یادگیری برنامه‌نویسی کامل VBA نیست.

## Macro چیست؟

Macro مجموعه‌ای از دستورهاست که Excel می‌تواند آن‌ها را اجرا کند. این دستورها می‌توانند با **VBA (Visual Basic for Applications)** نوشته شوند.

کاربردهای رایج:

- اجرای چند عملیات با یک دکمه
- قالب‌بندی خودکار گزارش
- پاک‌سازی یک فایل طبق روال ثابت
- مخفی/نمایش بخش‌هایی از گزارش
- آماده‌سازی خروجی برای چاپ

## فعال‌سازی دسترسی Macro

تنظیمات امنیتی Macroها را از **File → Options → Trust Center → Trust Center Settings → Macro Settings** می‌توان مدیریت کرد.

همچنین فایلی که Macro دارد باید با فرمت مناسب مانند `.xlsm` ذخیره شود.

> **هشدار:** Macro می‌تواند کد اجرا کند. فایل‌های ناشناس یا دریافت‌شده از منبع نامعتبر را بدون بررسی فعال نکنید.

## یک مثال ساده: نمایش یا مخفی کردن ستون

یک Button در تب Developer ایجاد کنید و Macro زیر را به آن متصل کنید:

```vb
Sub ToggleReportColumn()
    Columns("E").Hidden = Not Columns("E").Hidden
End Sub
```

با هر بار کلیک، ستون E مخفی یا دوباره نمایش داده می‌شود.

## چرا این برای Dashboard مفید است؟

فرض کنید Dashboard دو حالت دارد:

```text
Summary View
Detailed View
```

یک Button می‌تواند بخش جزئیات را نمایش یا پنهان کند و صفحه را برای مخاطب ساده‌تر نگه دارد.

## Button

Button برای اجرای یک Macro یا Action مناسب است.

سناریوهای مثال:

```text
Refresh Report
Show Details
Hide Details
Reset Filters
Export / Print
```

## چه زمانی VBA نرویم؟

اگر یک کار با Formula، Table، Pivot یا Slicer به شکل واضح و قابل نگهداری حل می‌شود، افزودن VBA همیشه تصمیم خوبی نیست.

VBA وابستگی بیشتری ایجاد می‌کند و ممکن است با سیاست امنیتی سازمان، نسخه Excel یا محیط اجرا مشکل داشته باشد.

> **اصل:** اول راه‌حل ساده و قابل نگهداری را امتحان کن؛ بعد سراغ Automation برو.

## تمرین

یک Dashboard کوچک بسازید و یک Button اضافه کنید که یک بخش جزئیات را مخفی/نمایش دهد.

### Challenge
Macro دوم بنویسید که وضعیت نمایش چند ستون را به حالت اولیه برگرداند:

```vb
Sub ResetReportView()
    Columns("D:F").Hidden = False
End Sub
```

سپس دو Button با عنوان‌های `Show Details` و `Reset View` برای آن بسازید.
