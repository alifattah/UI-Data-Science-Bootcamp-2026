# جلسه ۸-۱ — BI و مفهوم Dashboard

## هدف جلسه

در این جلسه می‌خواهیم از «تحلیل داده» به «ارائه نتیجه برای تصمیم‌گیری» برسیم. ابتدا Business Intelligence را به زبان ساده تعریف می‌کنیم و سپس می‌بینیم Dashboard چه مسئله‌ای را حل می‌کند.

## Business Intelligence چیست؟

**Business Intelligence (BI)** مجموعه‌ای از روش‌ها، فرایندها و ابزارهایی است که داده‌های یک سازمان را به اطلاعات قابل استفاده برای تصمیم‌گیری تبدیل می‌کند.

مثلاً یک شرکت ممکن است هزاران سفارش، هزینه تبلیغات، اطلاعات مشتری و موجودی انبار داشته باشد. وجود این داده‌ها به‌تنهایی کمک زیادی به مدیر نمی‌کند؛ سؤال اصلی این است که:

> «از این داده‌ها چه چیزی باید بفهمیم و بر اساس آن چه تصمیمی بگیریم؟»

BI کمک می‌کند این مسیر از داده خام تا تصمیم، منظم‌تر و سریع‌تر شود.

## Dashboard چیست؟

Dashboard یک نمای فشرده و هدفمند از مهم‌ترین شاخص‌ها و تحلیل‌های یک موضوع است.

یک داشبورد فروش ممکن است در یک صفحه این اطلاعات را نشان دهد:

- فروش کل
- تعداد سفارش
- میانگین مبلغ سفارش
- فروش ماهانه
- بهترین محصولات
- عملکرد مناطق
- فیلتر بازه زمانی

هدف Dashboard این نیست که تمام دیتاست را نمایش دهد. هدف این است که **مخاطب بتواند وضعیت را سریع درک کند و در صورت نیاز عمیق‌تر شود.**

## Report در برابر Dashboard

یک Report ممکن است جزئیات زیادی داشته باشد؛ Dashboard بیشتر روی خلاصه، مقایسه و وضعیت کلیدی تمرکز دارد.

| Report | Dashboard |
|---|---|
| جزئیات بیشتر | خلاصه و هدفمند |
| ممکن است چندین صفحه باشد | معمولاً نمای فشرده |
| مناسب بررسی عمیق | مناسب پایش و تصمیم سریع |
| اغلب با متن و جدول زیاد | معمولاً KPI + Chart + Filter |

این دو جایگزین هم نیستند. یک Dashboard خوب معمولاً به Report یا داده‌های جزئی‌تر متصل است.

## اولین سؤال: مخاطب کیست؟

قبل از ساخت داشبورد باید مشخص کنیم چه کسی از آن استفاده می‌کند.

برای مدیرعامل شاید این‌ها مهم باشند:

- Revenue
- Profit
- Growth
- Top Region

اما برای مدیر عملیات ممکن است این شاخص‌ها مهم‌تر باشند:

- تعداد سفارش‌های باز
- زمان پردازش
- Backlog
- خطاهای عملیاتی

پس Dashboard را بر اساس **کاربر و تصمیم او** طراحی می‌کنیم، نه صرفاً بر اساس چیزهایی که Excel می‌تواند نمایش دهد.

## KPI چیست؟

**Key Performance Indicator (KPI)** یک معیار قابل اندازه‌گیری است که وضعیت یا عملکرد یک هدف مهم را نشان می‌دهد.

مثلاً:

```text
هدف: افزایش فروش
KPI: Monthly Revenue
```

یا:

```text
هدف: بهبود خدمات
KPI: Average Response Time
```

هر عددی KPI نیست. KPI باید با یک سؤال یا هدف مشخص ارتباط داشته باشد.

## داستان‌سرایی با داده

داشبورد خوب فقط چند نمودار کنار هم نیست. باید یک مسیر منطقی برای نگاه کردن ایجاد کند.

مثلاً:

```text
فروش کل چقدر است؟
        ↓
آیا در حال رشد است؟
        ↓
کدام منطقه بهتر عمل کرده؟
        ↓
کدام محصول علت اصلی نتیجه است؟
```

این ترتیب باعث می‌شود کاربر از «وضعیت کلی» به «جزئیات قابل اقدام» حرکت کند.

## تمرین

برای یک فروشگاه آنلاین، سه مخاطب زیر را در نظر بگیرید:

1. مدیرعامل
2. مدیر فروش
3. مدیر بازاریابی

برای هرکدام ۴ KPI پیشنهاد دهید و توضیح دهید چرا برای آن شخص مهم‌اند.

### Challenge
یک Dashboard را روی کاغذ طراحی کنید. هنوز Excel باز نکنید. فقط مشخص کنید:

- عنوان داشبورد چیست؟
- کاربر آن چه کسی است؟
- ۳ KPI اصلی چیست؟
- ۲ نمودار اصلی چیست؟
- چه فیلترهایی لازم است؟
