# جلسه ۸-۴ — Slicer و Timeline؛ تعامل سریع با داشبورد

## چرا Slicer مهم است؟

وقتی داشبورد به دست مدیر یا مشتری می‌رسد، بهتر است برای فیلتر کردن داده مجبور نباشد هر بار وارد منوهای Excel شود. Slicer این کار را به یک انتخاب بصری تبدیل می‌کند.

## ساخت Slicer

اگر منبع داده یک Table یا PivotTable باشد، بر اساس آن می‌توان Slicer ایجاد کرد.

برای PivotTable:

**PivotTable Analyze → Insert Slicer**

برای Table معمولی نیز از بخش **Table Design → Insert Slicer** می‌توان استفاده کرد.

مثلاً برای فروش:

```text
Region
┌────────────┐
│ North      │
│ South      │
│ East       │
│ West       │
└────────────┘
```

با کلیک روی `North` فقط رکوردهای مرتبط نمایش داده می‌شوند.

## انتخاب چند مقدار

برای انتخاب چند آیتم می‌توان از Multiple Select در خود Slicer یا کلید `Ctrl` استفاده کرد.

مثلاً:

```text
North + East
```

یعنی گزارش فقط این دو منطقه را پوشش دهد.

## اتصال Slicer به چند Pivot

اگر چند PivotTable از یک Pivot Cache مشترک استفاده کنند، می‌توان یک Slicer را به چند گزارش متصل کرد.

مسیر معمول:

**Slicer → Report Connections**

سپس PivotTableهای موردنظر را علامت بزنید.

این کار برای داشبورد بسیار مهم است؛ چون یک فیلتر می‌تواند چند بخش صفحه را هم‌زمان کنترل کند.

## Timeline

Timeline نسخه زمانیِ Slicer است.

برای فیلد تاریخ استفاده می‌شود و امکان انتخاب بازه زمانی را فراهم می‌کند.

مثلاً:

```text
2025
[ Q1 ] [ Q2 ] [ Q3 ] [ Q4 ]
```

کاربر می‌تواند فقط یک فصل، یک ماه یا یک بازه را انتخاب کند.

## یک مثال واقعی

داشبورد فروش را در نظر بگیرید:

- Slicer → Region
- Slicer → Product Category
- Timeline → Order Date

کاربر می‌تواند:

```text
Region = North
Category = Electronics
Date = Last 3 Months
```

را انتخاب کند و تمام Pivotها و Chartهای متصل مطابق این انتخاب تغییر کنند.

## طراحی Slicer

Slicer خودش بخشی از UI داشبورد است، پس باید با Layout هماهنگ باشد.

موارد قابل تنظیم شامل:

- Slicer Style
- تعداد ستون‌های نمایش گزینه‌ها
- ارتفاع و عرض
- Caption
- ترتیب آیتم‌ها

اگر ۲۰ آیتم دارید، Slicer تک‌ستونه بسیار بلند می‌شود؛ تنظیم چند ستون می‌تواند فضای صفحه را بهتر مدیریت کند.

## یک نکته مهم درباره فیلترها

وجود چند Slicer باعث افزایش قدرت تعامل می‌شود، اما اگر تعداد آن‌ها زیاد شود، داشبورد شلوغ و گیج‌کننده می‌شود.

پس برای هر فیلتر یک سؤال مشخص داشته باشید:

> آیا این فیلتر واقعاً برای تصمیم کاربر لازم است؟

## تمرین

روی داشبورد فروش:

1. Slicer برای Region بسازید.
2. Slicer برای Category بسازید.
3. Timeline برای Date اضافه کنید.
4. هر سه را به دو PivotTable و یک PivotChart متصل کنید.
5. چند ترکیب مختلف انتخاب کنید و مطمئن شوید همه بخش‌ها هماهنگ تغییر می‌کنند.

### Challenge
داشبورد را طوری تنظیم کنید که با انتخاب یک Region، کاربر هم‌زمان فروش، تعداد سفارش و میانگین سفارش همان Region را ببیند.
