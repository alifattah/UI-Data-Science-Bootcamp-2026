# جلسه ۸-۵ — Form Controls برای تعامل با Dashboard

## هدف جلسه

در این جلسه با کنترل‌های فرم Excel آشنا می‌شویم و می‌بینیم چگونه عناصر ساده رابط کاربری را به سلول‌ها، فرمول‌ها و گزارش متصل کنیم.

## فعال کردن Developer

برای دسترسی به Form Controls معمولاً باید تب **Developer** را فعال کنیم:

**File → Options → Customize Ribbon → Developer**

پس از فعال‌سازی، ابزارهای مربوط به کنترل‌ها و Macroها در اختیارمان قرار می‌گیرند.

## کنترل‌های مهم

| کنترل | کاربرد |
|---|---|
| Button | اجرای یک Action یا Macro |
| Check Box | انتخاب روشن/خاموش |
| Option Button | انتخاب یکی از چند گزینه |
| Combo Box | انتخاب یک گزینه از فهرست |
| List Box | نمایش فهرست و انتخاب آیتم |
| Scroll Bar | تغییر تدریجی یک مقدار |
| Spin Button | افزایش یا کاهش مقدار عددی |

## Check Box و Cell Link

یک Check Box می‌تواند به یک Cell متصل شود. نتیجه معمولاً به شکل `TRUE` یا `FALSE` در آن Cell قرار می‌گیرد.

مثلاً:

```text
Check Box: Show Profit
Cell Link: H2
```

وقتی کاربر Checkbox را فعال می‌کند:

```text
H2 = TRUE
```

اکنون می‌توانیم در یک Formula بر اساس آن تصمیم بگیریم که Profit نمایش داده شود یا خیر.

## Combo Box

Combo Box برای انتخاب یک گزینه از یک فهرست مناسب است.

در **Format Control → Control** می‌توان `Input Range` را تعیین کرد؛ یعنی محدوده‌ای که گزینه‌های انتخاب از آن خوانده شوند.

`Cell Link` مشخص می‌کند انتخاب کاربر در کدام سلول ثبت شود.

در بسیاری از سناریوها Cell Link شماره گزینه را ذخیره می‌کند، بنابراین می‌توان با `INDEX` مقدار متناظر را پیدا کرد.

مثال:

```excel
=INDEX(A2:A6,H2)
```

## Option Button

Option Button برای انتخاب یکی از چند گزینه طراحی شده است.

مثلاً:

```text
(•) Revenue
( ) Profit
( ) Orders
```

در یک Group مناسب، کاربر فقط یکی را انتخاب می‌کند. مقدار انتخاب را می‌توان به یک Cell لینک کرد و سپس در Formula از آن استفاده کرد.

## List Box

List Box شبیه Combo Box است، اما چند گزینه را هم‌زمان روی صفحه نشان می‌دهد و فضای بیشتری مصرف می‌کند. در برخی تنظیمات امکان Multi Select نیز وجود دارد.

## Scroll Bar و Spin Button

این کنترل‌ها زمانی مفیدند که بخواهیم یک مقدار عددی را تعاملی تغییر دهیم.

مثلاً فرض کنید کاربر می‌خواهد Target فروش را بین `100` تا `500` میلیون تغییر دهد. Scroll Bar می‌تواند مقدار را کنترل کند و Formulaهای دیگر با تغییر مقدار، KPIهای داشبورد را به‌روزرسانی کنند.

## یک معماری ساده برای Dashboard

```text
Form Control
     ↓
Linked Cell
     ↓
Formula / Lookup
     ↓
Chart / KPI
```

Form Control خودش تحلیل نمی‌کند؛ بیشتر نقش «ورودی کاربر» را دارد.

## تمرین

یک گزارش بسازید که:

- Combo Box برای انتخاب `Revenue / Profit / Orders` داشته باشد.
- Cell Link انتخاب را نگه دارد.
- یک KPI بر اساس انتخاب کاربر تغییر کند.

سپس یک Check Box اضافه کنید که با فعال شدن، یک بخش از گزارش را نمایش دهد.
