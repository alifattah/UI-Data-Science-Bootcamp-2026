# فصل ۸ — ساخت داشبورد و پروژه پایانی Excel

> **هدف فصل:** یاد می‌گیریم چگونه خروجی‌های تحلیلی Excel را به یک گزارش مدیریتی منسجم، خوانا و تعاملی تبدیل کنیم. در ادامه PivotTable، Chart، Slicer، Dynamic Range و Form Controls را کنار هم قرار می‌دهیم.

## نقشه فصل

| جلسه | عنوان | خروجی |
|---|---|---|
| 08-01 | BI و مفهوم Dashboard | تشخیص هدف، مخاطب، KPI و تفاوت گزارش با داشبورد |
| 08-02 | طراحی داشبورد | طراحی Layout، سلسله‌مراتب بصری و انتخاب اجزای مناسب |
| 08-03 | Dynamic Reports و Drop-down | ساخت گزارش‌هایی که با انتخاب کاربر تغییر می‌کنند |
| 08-04 | Slicer، Timeline و اتصال کنترل‌ها | ساخت تعامل چندبخشی بین گزارش‌ها |
| 08-05 | Form Controls | Check Box، Combo Box، List Box، Option Button، Scroll Bar و Spinner |
| 08-06 | VBA و اتوماسیون داشبورد | اتصال Button و Controlها به Macroهای ساده |
| 08-07 | پروژه پایانی Dashboard | ساخت یک داشبورد فروش از صفر تا خروجی نهایی |

## اصل طراحی

یک Dashboard خوب قرار نیست تمام داده‌ها را نشان دهد. باید **سؤال‌های مهم مخاطب را سریع پاسخ دهد**.

```text
Question
   ↓
KPI / Metric
   ↓
Best Visualization
   ↓
Interaction
   ↓
Insight
```
