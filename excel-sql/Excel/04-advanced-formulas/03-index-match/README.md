# جلسه ۳ — INDEX و MATCH؛ Lookup منعطف‌تر

## چرا سراغ INDEX و MATCH می‌رویم؟

VLOOKUP در بسیاری از کارها عالی است، اما یک محدودیت معروف دارد: مقدار جست‌وجو باید در اولین ستون محدوده قرار داشته باشد.

وقتی ساختار جدول این محدودیت را ایجاد می‌کند، می‌توانیم از ترکیب `INDEX` و `MATCH` استفاده کنیم.

---

## 1. MATCH؛ پیدا کردن موقعیت

`MATCH` به‌جای اینکه مقدار متناظر را برگرداند، **موقعیت آن مقدار داخل یک محدوده** را پیدا می‌کند.

فرض کنید کدهای پرسنلی در `B2:B7` قرار دارند و شماره مورد جست‌وجو در `E2` است:

```excel
=MATCH(E2,B2:B7,0)
```

آرگومان سوم `0` یعنی تطبیق دقیق.

اگر مقدار مورد نظر سومین عنصر محدوده باشد، خروجی `MATCH` برابر ۳ می‌شود.

> **نکته:** خروجی MATCH شماره واقعی Row در Worksheet نیست؛ موقعیت در محدوده‌ای است که به تابع داده‌ایم.

---

## 2. INDEX؛ برگرداندن مقدار از یک محدوده

`INDEX` یک محدوده را می‌گیرد و بر اساس شماره ردیف و در صورت نیاز شماره ستون، مقدار متناظر را برمی‌گرداند.

مثلاً:

```excel
=INDEX(C2:C7,3)
```

یعنی سومین مقدار محدوده `C2:C7` را برگردان.

برای یک محدوده دوبعدی می‌توانیم سطر و ستون را هر دو مشخص کنیم:

```excel
=INDEX(A2:D8,3,2)
```

یعنی مقدار سطر سوم و ستون دوم محدوده را بده.

---

## 3. ترکیب INDEX + MATCH

حالا قسمت جذاب ماجرا:

```excel
=INDEX(C2:C7,MATCH(E2,B2:B7,0))
```

منطق فرمول دو مرحله‌ای است:

1. `MATCH` پیدا می‌کند مقدار E2 کجای ستون B قرار دارد.
2. `INDEX` مقدار همان موقعیت را از ستون C برمی‌گرداند.

این روش از نظر مفهومی خیلی مهم است: **یک تابع موقعیت را پیدا می‌کند و تابع دیگر مقدار آن موقعیت را برمی‌گرداند.**

---

## 4. چرا این ترکیب انعطاف‌پذیرتر است؟

فرض کنید جدول ما چنین ساختاری دارد:

| Name | Employee ID | Sales |
|---|---|---:|
| Sara | E201 | 128 |
| Reza | E202 | 154 |
| Mina | E203 | 117 |
| Amir | E204 | 182 |

اگر بخواهیم بر اساس Employee ID مقدار Sales را پیدا کنیم، VLOOKUP در این حالت باید محدوده‌ای را از ستون Employee ID شروع کند؛ در حالی‌که INDEX + MATCH بدون چنین وابستگی‌ای کار می‌کند.

```excel
=INDEX(C2:C5,MATCH(E2,B2:B5,0))
```

---

## 5. MATCH در جهت‌های مختلف

MATCH محدود به جست‌وجوی عمودی نیست. می‌توان آن را روی یک Row نیز اجرا کرد.

مثلاً:

```excel
=MATCH("Mar",B1:M1,0)
```

شماره موقعیت ماه March را در محدوده پیدا می‌کند.

این ویژگی برای ساخت Lookupهای دوطرفه در مدل‌های پیچیده‌تر بسیار مفید است.

---

## 6. یک مثال تحلیلی

فرض کنید می‌خواهیم با وارد کردن نام فروشنده، مقدار فروش او را پیدا کنیم.

| A | B | C |
|---|---|---:|
| Region | Salesperson | Revenue |
| North | Sara | 420000 |
| North | Reza | 510000 |
| South | Mina | 380000 |
| South | Amir | 460000 |

اگر نام فروشنده در `F2` باشد:

```excel
=INDEX(C2:C5,MATCH(F2,B2:B5,0))
```

به‌راحتی درآمد مربوط به او را برمی‌گردانیم.

---

## 7. خطاهای رایج

### MATCH مقدار را پیدا نمی‌کند
خروجی معمولاً `#N/A` است. قبل از پیچیده‌تر کردن فرمول، خود مقدار مورد جست‌وجو را بررسی کنید.

### فاصله اضافی
ممکن است `Sara` و `Sara ` متفاوت باشند.

### نوع داده متفاوت
یک کد ممکن است در یک سمت به صورت Number و در سمت دیگر به صورت Text ذخیره شده باشد.

### محدوده‌های نامنطبق
اگر محدوده‌ای که MATCH در آن موقعیت را پیدا می‌کند و محدوده‌ای که INDEX از آن خروجی می‌گیرد هم‌اندازه نباشند، امکان بروز خطای منطقی وجود دارد.

---

## 8. نگاه درست به Lookup

به جای حفظ کردن فرمول، این مدل ذهنی را نگه دارید:

```text
Key
 ↓
پیدا کردن موقعیت
 ↓
MATCH
 ↓
برگرداندن مقدار متناظر
 ↓
INDEX
```

وقتی این منطق را بفهمید، Lookupهای پیچیده‌تر هم خیلی قابل فهم‌تر می‌شوند.

---

## 🧩 تمرین

یک جدول شامل `Employee ID`، `Employee Name`، `Department` و `Salary` بسازید.

1. بر اساس Employee ID، Department را با `INDEX + MATCH` پیدا کنید.
2. همان مسئله را با VLOOKUP حل کنید و مقایسه کنید.
3. ساختار جدول را طوری تغییر دهید که Employee ID دیگر در اولین ستون نباشد. دوباره هر دو روش را امتحان کنید.
4. یک ID نامعتبر وارد کنید و رفتار فرمول را بررسی کنید.

---

## ✅ خلاصه

- `MATCH` موقعیت یک مقدار را پیدا می‌کند.
- `INDEX` مقدار یک موقعیت را برمی‌گرداند.
- ترکیب `INDEX + MATCH` محدودیت مهم VLOOKUP را دور می‌زند.
- این ترکیب یکی از مفاهیم مهم Lookup در Excel است.
