# جلسه ۴ — دستکاری و تحلیل داده‌های متنی

## چرا متن در Excel مهم است؟

در Datasetهای واقعی، همه چیز عدد نیست. نام مشتری، کد سفارش، ایمیل، نام شهر، شماره تماس و حتی شناسه‌هایی که ظاهری عددی دارند، معمولاً داده متنی هستند.

مثلاً کد زیر را ببینید:

```text
001728
```

اگر آن را به‌عنوان عدد ذخیره کنیم، صفرهای ابتدای آن ممکن است از بین بروند. چون با این کد قرار نیست جمع و تفریق انجام دهیم، از نظر تحلیلی بیشتر شبیه یک **شناسه متنی** است تا یک عدد.

در این جلسه یاد می‌گیریم متن را تمیز، تکه‌تکه، ترکیب و جست‌وجو کنیم.

---

## 1. الحاق با `&`

ساده‌ترین راه برای چسباندن چند مقدار به هم استفاده از `&` است:

```excel
=A2&" "&B2
```

اگر `A2` شامل `Sara` و `B2` شامل `Ahmadi` باشد، نتیجه:

```text
Sara Ahmadi
```

### مثال کاربردی

ساخت Full Name:

```excel
=FirstName&" "&LastName
```

یا ساخت کد سفارشی:

```excel
="ORD-"&A2
```

---

## 2. CONCAT و CONCATENATE

`CONCAT` برای اتصال چند مقدار مناسب است:

```excel
=CONCAT(A2:C2)
```

تابع قدیمی‌تر `CONCATENATE` نیز در نسخه‌های مختلف Excel دیده می‌شود:

```excel
=CONCATENATE(A2," ",B2)
```

در پروژه‌های جدید معمولاً بهتر است از گزینه‌های جدیدتر مثل `CONCAT` یا `TEXTJOIN` استفاده کنیم.

---

## 3. پیدا کردن یک عبارت با FIND و SEARCH

فرض کنید می‌خواهیم ببینیم رشته‌ای در متن یک سلول قرار دارد یا نه.

```excel
=FIND("excel",A2)
```

اگر متن وجود داشته باشد، موقعیت شروع آن را برمی‌گرداند.

`SEARCH` هم مشابه است:

```excel
=SEARCH("excel",A2)
```

تفاوت مهم:

- `FIND` نسبت به بزرگی و کوچکی حروف حساس است.
- `SEARCH` نسبت به Case حساس نیست.

مثلاً `SEARCH("EXCEL","I like Excel")` می‌تواند عبارت را پیدا کند.

> **نکته:** اگر متن پیدا نشود، این توابع خطا برمی‌گردانند. در کاربردهای واقعی می‌توانیم از `IFERROR` برای مدیریت این حالت استفاده کنیم.

---

## 4. استخراج با LEFT، RIGHT و MID

گاهی لازم است فقط قسمتی از یک رشته را جدا کنیم.

### LEFT

```excel
=LEFT(A2,4)
```

چهار کاراکتر اول را برمی‌گرداند.

### RIGHT

```excel
=RIGHT(A2,3)
```

سه کاراکتر آخر را برمی‌گرداند.

### MID

```excel
=MID(A2,5,4)
```

از کاراکتر پنجم، چهار کاراکتر استخراج می‌کند.

### مثال

فرض کنید کد زیر را داریم:

```text
IR-TEH-028
```

می‌توانیم با ترکیب این توابع بخش‌های مختلف کد را جدا کنیم.

---

## 5. LEN؛ طول رشته

```excel
=LEN(A2)
```

تعداد کاراکترهای متن را برمی‌گرداند.

این تابع برای کنترل کیفیت داده بسیار مفید است. مثلاً اگر همه کدهای ملی باید ۱۰ کاراکتر باشند، می‌توانیم طول آن‌ها را بررسی کنیم:

```excel
=LEN(A2)=10
```

---

## 6. TRIM؛ مبارزه با فاصله‌های اضافه

یکی از مشکلات رایج داده‌های متنی وجود فاصله اضافی است.

```excel
=TRIM(A2)
```

مثلاً این دو مقدار ممکن است ظاهراً یکی باشند:

```text
"Tehran"
"  Tehran  "
```

اما فاصله اضافی می‌تواند در Lookup، دسته‌بندی یا مقایسه مشکل ایجاد کند.

`TRIM` فاصله‌های اضافی را تا حد زیادی پاک می‌کند و داده را استانداردتر می‌سازد.

---

## 7. SUBSTITUTE و REPLACE

هر دو برای تغییر متن کاربرد دارند، اما منطقشان متفاوت است.

### SUBSTITUTE

وقتی می‌دانیم **چه عبارتی** باید جایگزین شود:

```excel
=SUBSTITUTE(A2,"-","/")
```

تمام `-`ها با `/` جایگزین می‌شوند.

### REPLACE

وقتی جایگاه و تعداد کاراکترها را می‌دانیم:

```excel
=REPLACE(A2,3,2,"XX")
```

از کاراکتر سوم، دو کاراکتر را با `XX` جایگزین می‌کند.

---

## 8. UPPER و LOWER

برای یکدست کردن متن انگلیسی:

```excel
=UPPER(A2)
=LOWER(A2)
```

این توابع مخصوصاً برای Standardization داده‌های متنی مفیدند.

مثلاً این سه مقدار:

```text
London
LONDON
london
```

می‌توانند به یک قالب تبدیل شوند.

---

## 9. TEXTBEFORE و TEXTAFTER

در نسخه‌های جدید Excel توابعی مثل `TEXTBEFORE` و `TEXTAFTER` جدا کردن متن را بسیار ساده‌تر کرده‌اند.

مثلاً:

```excel
=TEXTBEFORE(A2,"@");
```

بخش قبل از `@` را استخراج می‌کند و برای جدا کردن نام کاربری از Email بسیار مناسب است.

یا:

```excel
=TEXTAFTER(A2,"@");
```

دامنه Email را برمی‌گرداند.

> **توجه:** در صورت استفاده از نسخه‌ای از Excel که این توابع را پشتیبانی نمی‌کند، می‌توان همین مسئله را با ترکیب `LEFT`، `RIGHT`، `FIND` و توابع دیگر حل کرد.

---

## 10. TEXTSPLIT؛ شکستن متن در چند ستون

اگر داده‌ای مثل این داشته باشیم:

```text
Tehran | Iran
```

می‌توان با delimiter مشخص آن را به چند بخش تقسیم کرد:

```excel
=TEXTSPLIT(A2," | ")
```

نتیجه می‌تواند در چند سلول Spill شود:

```text
Tehran    |    Iran
```

این قابلیت برای جدا کردن داده‌های ترکیبی بسیار کاربردی است.

---

## 11. TEXTJOIN؛ چسباندن متن با جداکننده

برعکس TEXTSPLIT، می‌توان چند سلول را با یک جداکننده به هم وصل کرد:

```excel
=TEXTJOIN(" - ",TRUE,A2:C2)
```

آرگومان دوم (`TRUE`) می‌گوید سلول‌های خالی نادیده گرفته شوند.

مثلاً:

```text
A2 = Tehran
B2 = null
C2 = Iran
```

خروجی:

```text
Tehran - Iran
```

## 🧠 یک سناریوی واقعی

فرض کنید ستون `Customer Full Name`، ستون `Email` و ستون `Customer Code` را داریم.

برای آماده‌سازی داده می‌توانیم:

```text
TRIM
  ↓
Standardize text
  ↓
LEN / Validation
  ↓
TEXTBEFORE / TEXTAFTER
  ↓
Extract features
  ↓
TEXTJOIN / CONCAT
```

این دقیقاً بخشی از فرایند **Data Cleaning & Transformation** است.

---

## 🧩 تمرین جلسه

ستونی از Emailهای نمونه بسازید و برای هر رکورد:

1. نام کاربری را قبل از `@` استخراج کنید.
2. دامنه را بعد از `@` جدا کنید.
3. طول Email را با `LEN` به دست آورید.
4. متن را با `TRIM` پاک‌سازی کنید.
5. چند ستون اطلاعاتی را با `TEXTJOIN` به یک Label تبدیل کنید.

در مرحله بعد، چند رکورد عمداً فاصله اضافه یا حروف انگلیسی با Case متفاوت داشته باشند و آن‌ها را استاندارد کنید.

---

## ✅ خلاصه

- `&` و `CONCAT` برای اتصال متن‌اند.
- `FIND` و `SEARCH` برای پیدا کردن متن استفاده می‌شوند.
- `LEFT`، `MID` و `RIGHT` برای استخراج بخش‌هایی از رشته‌اند.
- `LEN` طول متن را مشخص می‌کند.
- `TRIM` برای حذف فاصله‌های اضافی بسیار مهم است.
- `SUBSTITUTE` و `REPLACE` هر دو برای تغییر متن هستند اما روش کار متفاوتی دارند.
- `TEXTSPLIT` و `TEXTJOIN` در نسخه‌های جدید Excel کار با متن را بسیار راحت‌تر می‌کنند.
