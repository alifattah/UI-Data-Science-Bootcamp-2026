# جلسه ۶ — منطق شرطی و توابع تصمیم‌گیری

## چرا منطق شرطی مهم است؟

تحلیل داده فقط جمع و میانگین نیست. گاهی باید بر اساس وضعیت هر رکورد تصمیم بگیریم.

مثلاً:

- اگر فروش بیشتر از هدف بود، وضعیت «موفق» ثبت شود.
- اگر مشتری بدهی داشته باشد، هشدار نمایش داده شود.
- اگر امتیاز بین چند بازه قرار گرفت، سطح عملکرد مشخص شود.

برای این کار از توابع منطقی استفاده می‌کنیم.

---

## 1. IF؛ ساده‌ترین تصمیم‌گیری

ساختار:

```excel
=IF(logical_test,value_if_true,value_if_false)
```

مثلاً:

```excel
=IF(D2>=70,"Pass","Fail")
```

اگر مقدار `D2` حداقل ۷۰ باشد، `Pass` و در غیر این صورت `Fail` برمی‌گردد.

### مثال واقعی

فرض کنید ستون `Amount Due` داریم:

```excel
=IF(E2>0,"Needs Payment","Settled")
```

---

## 2. ترکیب IF با AND

`AND` زمانی TRUE می‌شود که تمام شروط درست باشند.

```excel
=IF(AND(B2="Tehran",C2>=10),"Priority","Normal")
```

یعنی مشتری باید هم در تهران باشد و هم حداقل ۱۰ سفارش داشته باشد.

---

## 3. ترکیب IF با OR

در `OR` کافی است یکی از شرط‌ها برقرار باشد:

```excel
=IF(OR(C2="VIP",D2>5000000),"Important","Regular")
```

---

## 4. NOT؛ برعکس کردن یک شرط

```excel
=NOT(A2="Closed")
```

اگر مقدار `A2` بسته (`Closed`) نباشد، نتیجه TRUE خواهد بود.

---

## 5. IFERROR و IFNA

فرمول‌های واقعی ممکن است خطا تولید کنند. هدف از Error Handling این نیست که خطاها را پنهان کنیم؛ هدف این است که خروجی مناسب و قابل فهمی به کاربر بدهیم.

### IFERROR

```excel
=IFERROR(A2/B2,0)
```

اگر تقسیم با خطا مواجه شود، `0` نمایش داده می‌شود.

### IFNA

این تابع مشخصاً خطای `#N/A` را مدیریت می‌کند:

```excel
=IFNA(VLOOKUP(E2,A2:C20,3,FALSE),"Not Found")
```

این برای Lookupهایی که ممکن است Key موجود نباشد بسیار مفید است.

> **نکته:** استفاده از `IFERROR(...,0)` در تمام فرمول‌ها همیشه ایده خوبی نیست. اگر خطا نشان‌دهنده یک مشکل واقعی در داده باشد، صفر کردن آن ممکن است مشکل را پنهان کند.

---

## 6. SWITCH؛ نگاشت چند مقدار مشخص

وقتی می‌دانیم ورودی دقیقاً می‌تواند یکی از چند مقدار مشخص باشد، `SWITCH` خوانایی خوبی دارد.

مثلاً:

```excel
=SWITCH(A2,
"Excellent",5,
"Good",4,
"Average",3,
"Weak",2,
"Poor",1,
0)
```

در اینجا متن کیفی به امتیاز عددی تبدیل می‌شود.

`SWITCH` برای شرط‌های برابری مناسب است؛ اگر شرط‌ها شامل `>`, `<` یا بازه باشند، `IFS` انتخاب مناسب‌تری است.

---

## 7. IFS؛ چند شرط بدون IF تو در تو

فرض کنید امتیاز عملکرد را به چند سطح تبدیل کنیم:

```excel
=IFS(
D2>=90,"Excellent",
D2>=75,"Good",
D2>=60,"Average",
TRUE,"Needs Improvement"
)
```

Excel شرط‌ها را از بالا به پایین بررسی می‌کند و اولین شرط درست را برمی‌گرداند.

وجود `TRUE` در انتها مثل حالت «در غیر این صورت» عمل می‌کند.

---

## 8. IF تو در تو

قبل از IFS معمولاً از IFهای تو در تو استفاده می‌شد:

```excel
=IF(D2>=90,"Excellent",IF(D2>=75,"Good",IF(D2>=60,"Average","Weak")))
```

این روش هنوز معتبر است، اما با زیاد شدن شرط‌ها خوانایی سریعاً افت می‌کند.

> **قاعده عملی:** اگر شرط‌ها زیاد شدند، فرمول را خوانا نگه دارید؛ گاهی ساختن یک جدول Mapping و استفاده از Lookup از یک فرمول بسیار بلند بهتر است.

---

## 🧠 نگاه تحلیلی

توابع شرطی به ما اجازه می‌دهند داده خام را به **اطلاعات تصمیم‌گیری** تبدیل کنیم.

مثلاً:

```text
Raw Sales
   ↓
IF / AND / OR
   ↓
Performance Category
   ↓
Dashboard / Report
```

این همان جایی است که Formula نویسی از محاسبه ساده فاصله می‌گیرد و وارد تحلیل می‌شود.

---

## 🧩 تمرین

جدول عملکرد فروشندگان بسازید:

`Name | Revenue | Target | Complaints | Status`

سپس:

1. مشخص کنید هر فروشنده به Target رسیده است یا نه.
2. فروشنده‌ای که هم به Target رسیده و هم کمتر از ۳ شکایت دارد، `Top Performer` شود.
3. فروشندگان را با IFS به سه سطح تقسیم کنید.
4. برای یک Lookup ناموفق، با IFNA پیام خوانا نمایش دهید.

---

## ✅ خلاصه

- `IF` برای تصمیم‌گیری شرطی است.
- `AND` تمام شروط را بررسی می‌کند.
- `OR` با برقرار بودن حداقل یک شرط TRUE می‌شود.
- `NOT` نتیجه منطقی را معکوس می‌کند.
- `IFERROR` و `IFNA` برای مدیریت خطا هستند.
- `SWITCH` برای مقایسه یک مقدار با چند حالت مشخص مناسب است.
- `IFS` برای چند شرط پشت‌سرهم و خواناتر از IFهای تو در تو است.
