# فصل ۴ — توابع و فرمول‌های پیشرفته Excel

> در این فصل از فرمول‌های ساده عبور می‌کنیم و یاد می‌گیریم چطور با منطق شرطی، Lookup، توابع متنی، Named Range و Excel Table مسئله‌های واقعی‌تری را حل کنیم.

## هدف فصل

در پایان فصل باید بتوانید:

- فرمول‌های ترکیبی و چندمرحله‌ای طراحی کنید.
- با `SUMPRODUCT`، `SUBTOTAL` و `AGGREGATE` برای محاسبات کاربردی کار کنید.
- با `VLOOKUP` و `HLOOKUP` داده‌ی مرتبط را پیدا کنید.
- منطق `INDEX + MATCH` را بفهمید و از آن برای Lookup منعطف استفاده کنید.
- متن را استخراج، پاک‌سازی و ترکیب کنید.
- از `IF`، `AND`، `OR`، `NOT`، `IFERROR`، `IFNA`، `SWITCH` و `IFS` برای تصمیم‌گیری استفاده کنید.
- محاسبات شرطی را با `SUMIFS`، `COUNTIFS`، `AVERAGEIFS`، `MAXIFS` و `MINIFS` انجام دهید.
- Named Range و Excel Table را برای ساخت مدل‌های خواناتر و قابل توسعه به کار ببرید.
- منطق آرایه‌ای و فرمول‌های چندسلولی را درک کنید.

## مسیر جلسات

| جلسه | عنوان | خروجی |
|---|---|---|
| 01 | فرمول‌های پیشرفته و توابع چندمنظوره | حل محاسبات ترکیبی و کنترل داده‌های مخفی/خطادار |
| 02 | VLOOKUP و HLOOKUP | اتصال اطلاعات بین جدول‌ها |
| 03 | INDEX و MATCH | Lookup منعطف بدون وابستگی به ستون اول |
| 04 | پردازش و دستکاری متن | استخراج، پاک‌سازی و ترکیب Stringها |
| 05 | Named Range و Excel Table | ساخت مدل‌های خواناتر و قابل توسعه |
| 06 | منطق شرطی و توابع تصمیم‌گیری | دسته‌بندی و کنترل خروجی‌ها |
| 07 | محاسبات شرطی و آرایه‌ای | تحلیل چندشرطی و فرمول‌های پیشرفته |

## نکته برای تدریس

این فصل را بهتر است با مسئله شروع کنید، نه با اسم تابع. ابتدا سؤال کسب‌وکاری را مطرح کنید، بعد نشان دهید که برای حل آن به چه تابع یا ترکیبی از توابع نیاز داریم.

**مثال:** «قیمت محصول در جدول دیگری است؛ چطور قیمت را کنار هر سفارش بیاوریم؟» سپس `VLOOKUP` را معرفی کنید.
