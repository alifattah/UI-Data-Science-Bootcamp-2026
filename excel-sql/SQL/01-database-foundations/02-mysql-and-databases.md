# درس ۲ — شروع کار با MySQL و مدیریت Database

## خروجی این درس

در پایان می‌توانید به MySQL متصل شوید، یک دیتابیس بسازید، دیتابیس فعال را انتخاب کنید، فهرست دیتابیس‌ها را ببینید و با احتیاط یک دیتابیس را حذف کنید.

## ۱. MySQL Server و ابزار اتصال

برای اجرای SQL به یک نمونه فعال از MySQL Server نیاز داریم. ابزاری مثل DataGrip یا MySQL Workbench فقط محیطی برای نوشتن و اجرای دستورهاست؛ خود پایگاه داده روی سرویس MySQL نگهداری می‌شود.

دو روش متداول برای کار:

- **محیط گرافیکی:** در DataGrip یک Data Source از نوع MySQL بسازید، آدرس میزبان، پورت، نام کاربری و رمز عبور را وارد کنید و اتصال را آزمایش کنید. پس از اتصال، یک Query Console باز کنید.
- **خط فرمان:** در ترمینال دستور زیر را اجرا کنید:

```bash
mysql -u root -p
```

پس از وارد کردن رمز عبور، وارد محیط تعاملی MySQL می‌شوید. نام کاربری `root` در این مثال صرفاً برای محیط آموزشی است؛ در پروژه واقعی بهتر است برای هر کاربر دسترسی متناسب با وظیفه‌اش تعریف شود.

## ۲. مشاهده دیتابیس‌ها

```sql
SHOW DATABASES;
```

این دستور دیتابیس‌هایی را که کاربر فعلی اجازه مشاهده آن‌ها را دارد فهرست می‌کند.

## ۳. ساخت دیتابیس

برای ایجاد فضای کاری بوت‌کمپ:

```sql
CREATE DATABASE bootcamp_retail
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;
```

- **Character Set** مشخص می‌کند چه نویسه‌هایی قابل ذخیره‌سازی باشند و کدگذاری متن چگونه انجام شود. `utf8mb4` انتخاب مناسبی برای متن فارسی، انگلیسی و نویسه‌های Unicode است.
- **Collation** قواعد مقایسه و مرتب‌سازی متن را تعیین می‌کند. پسوند `_ai_ci` در این Collation به‌طور خلاصه به accent-insensitive و case-insensitive بودن مقایسه اشاره دارد.

اگر دیتابیس از قبل ساخته شده باشد، برای جلوگیری از خطای وجود داشتن آن می‌توان از این فرم استفاده کرد:

```sql
CREATE DATABASE IF NOT EXISTS bootcamp_retail
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;
```

> نکته: Collationهای موجود به نسخه MySQL وابسته‌اند. اگر سرور شما این Collation را نمی‌شناسد، ابتدا نسخه و Collationهای قابل استفاده را بررسی کنید.

## ۴. انتخاب دیتابیس فعال

```sql
USE bootcamp_retail;
```

از این لحظه دستورهای ساخت جدول و Queryها، در صورت مشخص نکردن نام دیتابیس، در همین دیتابیس اجرا می‌شوند.

برای اطمینان از دیتابیس فعال:

```sql
SELECT DATABASE();
```

## ۵. حذف دیتابیس

```sql
DROP DATABASE bootcamp_retail;
```

این دستور کل دیتابیس و جدول‌های داخل آن را حذف می‌کند. این عملیات را روی داده واقعی یا دیتابیس مشترک اجرا نکنید.

فرم محافظه‌کارانه‌تر:

```sql
DROP DATABASE IF EXISTS bootcamp_retail;
```

`IF EXISTS` فقط از خطا در صورت نبودن دیتابیس جلوگیری می‌کند؛ مانع حذف دیتابیس موجود نمی‌شود.

## ۶. Storage Engine در MySQL

Storage Engine بخشی از MySQL است که نحوه ذخیره‌سازی و دسترسی به داده‌های جدول را مدیریت می‌کند.

برای مشاهده Engineهای در دسترس:

```sql
SHOW ENGINES;
```

در اغلب نسخه‌های جدید MySQL، **InnoDB** موتور پیش‌فرض و انتخاب معمول برای جدول‌های عملیاتی است.

| ویژگی | InnoDB | MyISAM |
|---|---|---|
| تراکنش و Rollback | پشتیبانی می‌کند | پشتیبانی نمی‌کند |
| Foreign Key | پشتیبانی می‌کند | پشتیبانی نمی‌کند |
| قفل‌گذاری | عمدتاً در سطح رکورد | در سطح جدول |
| کاربرد متداول | سامانه‌های تراکنشی و داده‌های مرتبط | موتور قدیمی‌تر با محدودیت‌های بیشتر |

برای این بوت‌کمپ از InnoDB استفاده می‌کنیم؛ زیرا رابطه میان جدول‌ها و یکپارچگی داده برای تحلیل قابل اعتماد ضروری است.

## اجرای عملی

دستورها را به ترتیب اجرا کنید:

```sql
CREATE DATABASE IF NOT EXISTS bootcamp_retail
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;

SHOW DATABASES;

USE bootcamp_retail;

SELECT DATABASE();

SHOW ENGINES;
```

## تمرین

1. دیتابیسی با نام `sales_lab` بسازید.
2. Character Set آن را `utf8mb4` قرار دهید.
3. آن را انتخاب کنید و با `SELECT DATABASE()` از انتخاب درست مطمئن شوید.
4. فهرست دیتابیس‌ها را نمایش دهید.
5. فعلاً دیتابیس را حذف نکنید؛ فقط دستور حذف را بنویسید و توضیح دهید چرا اجرای آن نیازمند احتیاط است.

## نکات کلیدی

- Client ابزار اتصال است؛ Server محل اجرای DBMS است.
- `CREATE DATABASE` دیتابیس می‌سازد و `USE` آن را انتخاب می‌کند.
- برای متن چندزبانه از `utf8mb4` استفاده کنید.
- پیش از `DROP DATABASE` حتماً نام و محیط اجرا را بررسی کنید.
- در این مسیر آموزشی، InnoDB را مبنا قرار می‌دهیم.
