# ماژول ۱ — مبانی پایگاه داده و آماده‌سازی محیط SQL

در این ماژول از شناخت مفاهیم پایه شروع می‌کنیم و به ساخت یک دیتابیس قابل استفاده برای تمرین‌های تحلیل داده می‌رسیم.

## پیش‌نیاز

آشنایی مقدماتی با فایل‌ها، جدول‌ها و مفهوم داده کافی است. تجربه برنامه‌نویسی برای شروع این ماژول الزامی نیست.

## خروجی نهایی ماژول

در پایان این ماژول باید بتوانید یک پایگاه داده ساده برای فروشگاه آنلاین طراحی کنید، جدول‌های اصلی آن را بسازید، داده را وارد کنید و رابطه میان موجودیت‌ها را با کلیدها مشخص کنید.
