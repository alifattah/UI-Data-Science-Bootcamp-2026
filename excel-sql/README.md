# Excel & SQL — Data Science Bootcamp 2026

این بخش از بوت‌کمپ به مهارت‌های **Excel** و **SQL / Database** اختصاص دارد. هدف، آموزش ابزارها صرفاً به‌عنوان نرم‌افزار نیست؛ بلکه ساختن توانایی حل مسئله، آماده‌سازی داده، تحلیل و گزارش‌دهی است.

## ساختار

- `curriculum.md` — نقشه راه جلسه‌به‌جلسه
- `lesson-notes.md` — درسنامه‌های کوتاه و قابل مرور برای تمام فصل‌ها
- `practice/` — فایل‌ها و تمرین‌های عملی که در ادامه اضافه می‌شوند

## شیوه یادگیری هر جلسه

1. مفهوم و مسئله واقعی
2. Live Demo توسط مدرس
3. تمرین هدایت‌شده
4. Challenge مستقل
5. جمع‌بندی و Cheat Sheet
